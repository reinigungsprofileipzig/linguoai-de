Ein Werkzeug, ein klarer Ablauf

Du kümmerst dich um die Sprache. LinguoAI kümmert sich um den Rest.

Kein undurchsichtiger Ein-Klick-Zauber: Jeder wichtige Baustein bleibt wählbar – von der Transkription über den Übersetzer bis zur Stimme und zum verwendeten Gerät.

Was LinguoAI kann

Alles für die neue Sprachfassung.

Die Desktop-Oberfläche, die CLI und die Colab-Version verwenden dieselbe robuste Verarbeitung im Hintergrund.

01

Sprache präzise erkennen

Faster-Whisper verarbeitet die Tonspur in überlappenden Abschnitten und behält echte Zeitmarken. Das Whisper-Modell, CPU/GPU und Rechenformat stellst du selbst ein.

  • Faster-Whisper
  • Spracherkennung automatisch oder fest
  • Datei & Ordner
02

Passend übersetzen

Wähle Google, DeepL, Gemini oder das lokale NLLB-200. Ein zweiter Dienst wird nur dann verwendet, wenn du ihn ausdrücklich als Fallback aktivierst.

  • NLLB lokal auf CPU oder CUDA
  • Eigene kompatible NLLB-Modelle
  • Optionale Gemini-Textoptimierung
03

Die richtige Stimme wählen

Online-Stimme, lokales ONNX-Modell oder eine autorisierte Referenzaufnahme: Edge, gTTS, Piper und Chatterbox sind pro Auftrag frei wählbar.

04

Im Timing bleiben

Jeder Sprachclip wird normalisiert, an sein Zeitfenster angepasst und samplegenau eingeordnet. Nachfolgende Sätze werden nicht einfach verschoben.

  • Begrenzte Tempoanpassung
  • Exaktes Medienende

Untertitel inklusive

Zu jedem fertigen Video entstehen eine SRT-Datei mit dem Originaltext und eine zweite mit der Übersetzung. So bleibt das Ergebnis flexibel nutzbar.

06

Sicher und nachvollziehbar arbeiten

Temporäre Ergebnisse werden erst veröffentlicht, wenn Video und beide Untertitel vollständig sind. Abbruch, begrenzte Wiederholungen, geschützte Zielpfade und redigierte API-Schlüssel vermeiden böse Überraschungen.

  • Abbrechen
  • Rollback
  • Timeouts
  • Keine Schlüssel in Logs

So arbeitet LinguoAI

Sechs Schritte. Ein fertiges Video.

Im Fortschrittsbereich siehst du jederzeit, was gerade passiert. Die einzelnen Modelle werden erst geladen, wenn sie wirklich gebraucht werden.

  1. 01
    Video einlesenFFmpeg prüft Bild, Ton und Dauer.
  2. 02
    Ton extrahierenDie Quelle wird als 16-kHz-Audio vorbereitet.
  3. 03
    TranskribierenWhisper erkennt Text und Zeitfenster.
  4. 04
    ÜbersetzenDer gewählte Dienst überträgt jeden Cue.
  5. 05
    VertonenDeine TTS-Engine erzeugt die neue Stimme.

Wo deine Daten verarbeitet werden

„Lokal“ und „online“ bleiben klar getrennt.

LOKALNLLB · Piper · Chatterbox

Nach dem Download in deiner gewählten Laufzeit. In Colab bedeutet das innerhalb der temporären Google-VM.

ONLINEGoogle · DeepL · Gemini

Erhalten Textabschnitte nur bei Auswahl oder als ausdrücklich aktivierter Fallback.

ONLINEEdge TTS · gTTS

Senden jeden zu vertonenden übersetzten Cue an den jeweiligen Online-Sprachdienst.

Referenzstimmen enthalten biometrisch sensible Merkmale. Die Bestätigung in LinguoAI ersetzt keine Einwilligung; auch Piper-Engine und Stimmenmodell können getrennte Lizenzen besitzen.

Voraussetzungen installieren

Du brauchst Python 3.10 oder neuer sowie FFmpeg und ffprobe. Für Chatterbox wird Python 3.11 empfohlen. Öffne danach eine neue PowerShell.

2

Eigene Umgebung anlegen

Die virtuelle Umgebung hält LinguoAI und seine Pakete sauber vom restlichen System getrennt.

3

Oberfläche öffnen

Wähle Video, Ziel, Übersetzer und Stimme. Der Systemcheck zeigt dir direkt, falls noch ein Paket oder Modell fehlt.

PowerShell · Basiseinrichtung 
# FFmpeg einmalig installieren
winget install --id Gyan.FFmpeg --exact

# Im Projektordner ausführen
cd "C:\Pfad\zu\LinguoAI-2.0.0"
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1

python -m pip install --upgrade pip
python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
python -m pip install -e ".[desktop]"
ffmpeg -version
ffprobe -version
python -m linguoai

Das Beispiel richtet bewusst die CPU-Version ein. Für NVIDIA wählst du zuerst den passenden Befehl im PyTorch-Installationsassistenten. Edge TTS und gTTS sind bereits dabei. Für Piper installierst du .[desktop,piper], für Chatterbox in einer eigenen Umgebung .[desktop,voice-clone].

gTTS / Google-Voice nutzen +

gTTS ist im Basispaket enthalten. Einzeln kann es so installiert werden:

python -m pip install gTTS
python -m linguoai -i quelle.mp4 -o ziel.mp4 -l de --tts-engine gtts
Piper lokal ergänzen +

In derselben virtuellen Umgebung installieren und danach eine passende Stimme laden:

python -m pip install -e ".[desktop,piper]"
New-Item -ItemType Directory -Force ".\Stimmen"
python -m piper.download_voices --download-dir ".\Stimmen" de_DE-thorsten-medium

Wegen der Audio-/Torch-Abhängigkeiten wird eine eigene Python-3.11-Umgebung empfohlen:

Rechenleistung sinnvoll verteilen

CPU und GPU sind keine Alles-oder-nichts-Entscheidung.

Whisper, NLLB und die lokale Stimme lassen sich getrennt platzieren. So kannst du klein anfangen und nur den Teil auf die GPU legen, der wirklich davon profitiert.

WhisperCPU · int8
NLLBGPU · CUDA
PiperCPU

Wichtig: Die Auswahl „GPU“ installiert CUDA nicht automatisch.
  • NLLB & Chatterbox

    Benötigen eine passende CUDA-Ausgabe von PyTorch.

    Benötigt zusätzlich CUDA-12-cuBLAS und cuDNN 9 im Systempfad.

  • Piper

    Nutzt ONNX Runtime: onnxruntime-gpu statt der CPU-Ausgabe installieren.

Der vollständige Werkzeugkasten

Alle Funktionen im Detail.

Du musst nicht jede Einstellung kennen, um anzufangen. Wenn du später mehr Kontrolle brauchst, findest du hier den kompletten Umfang – ohne versteckte Versprechen.

01Dateien und Aufträge+
  • Ein einzelnes Video oder alle direkt enthaltenen Videos eines Ordners verarbeiten.
  • Eingaben: MP4, MKV, MOV, AVI, WEBM und M4V; Ausgaben: MP4, MKV oder MOV.
  • Automatischer Ausgabevorschlag, kollisionsfreie Namen und kontrolliertes Überschreiben.
  • Fortschritt pro Datei, aktueller Arbeitsschritt, Abbruch und technisches Protokoll.

Ordner werden bewusst nicht rekursiv durchsucht. In Colab läuft jeweils ein Video pro Auftrag.

02Transkription mit Faster-Whisper+
  • Modelle von tiny bis large-v3, zusätzlich eigene Modellwerte.
  • Quellsprache automatisch erkennen oder als Sprachcode festlegen.
  • CPU, NVIDIA-CUDA oder automatische Auswahl; int8, float16 und float32 konfigurierbar.
  • Überlappende Audioabschnitte, echte Zeit-Offsets und Bereinigung doppelter Segmente.
  • Chunklänge, Überlappung und Worker-Anzahl über erweiterte Optionen beziehungsweise CLI.
03Übersetzung und Textschutz+
  • NLLB-200 lokal, Google Translate ohne Schlüssel, DeepL-SDK oder Gemini.
  • Optionaler Fallback nur nach ausdrücklicher Auswahl – sonst wird nur ein Anbieter kontaktiert.
  • URLs, E-Mail-Adressen, Währungen, Einheiten und Prozentwerte werden beim Übersetzen geschützt.
  • Timeouts, begrenzte Wiederholungen und Cache für identische Textabschnitte.
  • Optional korrigiert Gemini das Whisper-Transkript, ohne Segment-IDs oder Zeiten zu ändern.
  • Eigene NLLB-kompatible Modelle, feste Revisionen, FLORES-Codes, Batch- und Tokenlimits.

Das voreingestellte NLLB-600M-Modell steht unter CC-BY-NC-4.0, ist ein Forschungsmodell und keine zertifizierte Produktionsübersetzung. Ergebnisse immer prüfen.

04Edge, gTTS, Piper und Chatterbox+
  • Edge: automatische Standardstimme oder eigene vollständige Edge-Stimmen-ID.
  • gTTS: Google Translate Text-to-Speech mit automatischer Zielsprache oder Sprachcode.
  • Piper: ONNX plus passende JSON, optionale Sprecher-ID und einstellbares Sprechtempo.
  • Chatterbox V2: Referenzprüfung, Ausdruck, CFG-Stärke, Rechtebestätigung und Wasserzeichen.
  • Lokale Engine auf CPU, CUDA oder automatisch mit CPU-Fallback betreiben.
  • Modelle werden nur für die ausgewählte Engine geladen und anschließend wieder freigegeben.

gTTS und Edge sind Online-Dienste und keine Stimmklone. LinguoAI lädt Piper-Modelle, trainiert sie aber nicht. Pro Auftrag wird eine Stimme verwendet. Chatterbox lehnt Referenzen unter 0,5 oder über 60 Sekunden ab und empfiehlt praktisch 6–10 Sekunden.

05Timing, Ton und Export+
  • Jeden Clip auf 48-kHz-Mono-PCM normalisieren und samplegenau positionieren.
  • Zu lange Sprache innerhalb einer konfigurierbaren Grenze beschleunigen.
  • Warnung bei starker Beschleunigung; kontrollierter Fehler statt unverständlicher Ausgabe.
  • Exakte Enddauer, übernommene Metadaten/Kapitel und möglichst unveränderter Videostream.
  • Atomare Ergebnisgruppe aus neuem Video, Original-SRT und Übersetzungs-SRT.
06Desktop-Oberfläche und CLI+
  • Drei GUI-Tabs: Start, Erweitert und Protokoll; dazu Hell- und Dunkelmodus.
  • Dynamische Felder, Systemcheck, lokale/online Kennzeichnung und Datenschutzhinweis.
  • Ergebnisvideo oder Ausgabeordner direkt öffnen; Protokoll kopieren oder leeren.
  • Tastatur: Strg+O, Strg+Enter und Esc.
  • CLI für Datei-/Ordnerjobs mit allen Geräte-, Modell-, Timeout- und Debugoptionen.
07Colab, Drive und sichere Pfade+
  • Geschützte Gradio-Weboberfläche mit zufälligem Passwort pro Sitzung.
  • Video, Piper-Dateien und Referenzaufnahme per Upload oder relativem MyDrive-Pfad.
  • Optionaler Modellcache und atomare Ergebniskopie in Google Drive.
  • Drei Browser-Downloads, 5-GB-Uploadlimit und automatische Bereinigung temporärer Ergebnisse.
  • Drive-Pfade bleiben innerhalb von MyDrive; Drive wird nicht als öffentlicher Downloadordner freigegeben.
08Was LinguoAI bewusst nicht verspricht+
  • Synchrones Timing ist keine Lippenbewegungs-Synchronisation; das Bild wird nicht verändert.
  • Die neue Sprachspur ersetzt den Originalton vollständig. Musik, Atmosphäre und Geräusche werden derzeit nicht übernommen.
  • Keine Sprechererkennung und keine automatische Mehrsprecher-Zuweisung.
  • Transkript, Übersetzung, Aussprache und Stimmähnlichkeit vor Veröffentlichung immer prüfen.
  • Colab-GPU, Sitzungslänge und Abschluss großer Jobs sind nicht garantiert.

Noch unsicher?

Häufige Fragen, klar beantwortet.

Für den ersten Versuch reichen ein kurzes Video, Edge TTS und die Standardeinstellungen.

Kann ich LinguoAI ohne Installation benutzen?+

Ja. Öffne das vorbereitete Notebook über den Button „In Colab öffnen“ und wähle dort „Laufzeit → Alle ausführen“. Das Notebook lädt das Quellcode-ZIP automatisch über die gesicherte Download-Adresse dieser Website. Du brauchst dafür nur ein Google-Konto; der Gradio-Link funktioniert, solange die Colab-Sitzung aktiv ist.

Kann LinguoAI meine eigene Stimme verwenden?+

Ja. Chatterbox übernimmt eine autorisierte Stimme aus einer kurzen Referenzaufnahme. Alternativ kannst du mit Piper ein bereits trainiertes eigenes ONNX-Modell laden. Edge TTS bietet nur fertige Katalogstimmen; gTTS nutzt Google-Sprachcodes, aber keine eigene Stimmkopie.

Läuft das Programm vollständig lokal?+

Mit Faster-Whisper, NLLB und Piper oder Chatterbox läuft die Verarbeitung nach den erstmaligen Modell-Downloads in der gewählten Laufzeit. Auf dem Desktop ist das dein Rechner; in Colab ist es die temporäre Google-VM. Edge TTS, gTTS, Google Translate, DeepL und Gemini sind Onlinedienste.

Brauche ich eine starke Grafikkarte?+

Nein. Whisper, NLLB und Piper funktionieren auf der CPU. Chatterbox läuft ebenfalls, ist dort aber deutlich langsamer. Für längere Projekte ist eine NVIDIA-GPU hilfreich.

Was bekomme ich am Ende?+

Ein neu vertontes Video sowie zwei SRT-Dateien: eine mit dem erkannten Originaltext und eine mit der Übersetzung. Das Quellvideo selbst bleibt unverändert.

Kann ich Dateien direkt aus Google Drive laden?+

Ja, in der Colab-Oberfläche. Du kannst einen sicheren relativen Pfad innerhalb von MyDrive angeben und Ergebnisse wieder in einen Drive-Ordner schreiben lassen.

Welche Sprachen unterstützt die eigene Referenzstimme?+

Chatterbox Multilingual V2 unterstützt 23 Basissprachen, darunter Deutsch, Englisch, Französisch, Spanisch, Italienisch, Portugiesisch, Polnisch, Türkisch, Japanisch, Koreanisch und Chinesisch. Piper hängt von der Sprache des gewählten Modells ab. gTTS unterstützt viele Google-Translate-Sprachcodes, aber keine Referenzstimmen.

Bereit für die erste Fassung?

Ein kurzes Testvideo ist der beste Anfang.

Starte mit Edge TTS oder gTTS und den Standardwerten. Wenn der Ablauf passt, wechselst du in Ruhe zu einer lokalen oder eigenen Stimme.
