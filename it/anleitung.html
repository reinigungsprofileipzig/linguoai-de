Windows e Linux

Installa localmente

È necessario Python 3.10 o versione successiva, nonché FFmpeg e ffprobe. Python 3.11 è consigliato per Chatterbox. Quindi apri un nuovo PowerShell.

Carica la versione 2.2.1 ↓

Scaricarlo, decomprimerlo completamente e seguire le istruzioni locali.

PowerShell · Configurazione di base 
# FFmpeg einmalig installieren
winget install --id Gyan.FFmpeg --exact

# Im entpackten Projektordner ausführen; Pfad anpassen
cd "C:\Pfad\zu\LinguoAI-2.2.1"
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1

python -m pip install --upgrade pip
python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
python -m pip install -e ".[desktop]"
ffmpeg -version
ffprobe -version
python -m linguoai

L'esempio imposta deliberatamente la versione CPU. Per NVIDIA selezionare prima il comando appropriato in Procedura guidata di installazione PyTorch. Edge TTS e gTTS sono già inclusi. Per Piper si installa .[desktop,piper], per Chatterbox nel proprio ambiente .[desktop,voice-clone].

La tua prima attività nell'interfaccia
  1. Seleziona video

    Fare clic su "File..." sotto "Avvia". Viene suggerito il percorso target.

  2. Imposta le lingue

    scegliere la lingua di destinazione; la lingua di partenza potrebbe essere riconosciuta automaticamente.

  3. Scegli traduttore

    Per locale: NLLB. Per un test veloce: Google. DeepL/Gemini necessitano della chiave; anche l'ottimizzazione separata Gemini.

  4. Determina la voce

    Testare immediatamente Edge o gTTS; Puoi configurare Piper o Chatterbox in "Avanzate".

  5. Inizia l'elaborazione

    monitorare i progressi; alla fine il video ed entrambi i file SRT si aprono direttamente.

Voce di riferimento · Consigliato GPU

Aggiungi Piper localmente

Installa nello stesso ambiente virtuale e quindi carica una voce adatta:

python -m pip install -e ".[desktop,piper]"
New-Item -ItemType Directory -Force ".\Stimmen"
python -m piper.download_voices --download-dir ".\Stimmen" de_DE-thorsten-medium

Piper: ONNX più JSON corrispondente, ID altoparlante opzionale e velocità di conversazione regolabile.

Voce di riferimento propria con Chatterbox

A causa delle dipendenze audio/torcia, si consiglia un ambiente Python-3.11 dedicato:

py -3.11 -m venv .venv-chatterbox
.\.venv-chatterbox\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -e ".[desktop,voice-clone]"
python -m linguoai
  • 6-10 secondi, una persona, poco riverbero, nessuna musica o rumore di fondo.
  • Download del modello da circa 3,7 GB; CPU è possibile, ma molto lento per i video più lunghi.
  • L'installazione nativa è sperimentale; Colab o Linux sono più affidabili per i problemi dei pacchetti audio.
Usa la tua voce in modo responsabile

Per Chatterbox, la conferma che è possibile utilizzare la voce è obbligatoria. Utilizza la tua registrazione o ottieni un'autorizzazione esplicita. L'output contiene anche una filigrana PerTh incorporata.

Le voci di riferimento contengono caratteristiche biometricamente sensibili. La conferma in LinguoAI non sostituisce il consenso; Il motore Piper e il modello vocale possono anche avere licenze separate.

Per processi ripetibili

Riga di comando

Questo esempio si traduce localmente in NLLB e utilizza un modello Piper. Per l'automazione sono disponibili le stesse impostazioni dello GUI.

Propri output e percorsi del modello

PowerShell · Piper localmente 
python -m linguoai `
  --input "C:\Videos\quelle.mp4" `
  --output "C:\Videos\quelle.de.mp4" `
  --language de `
  --service nllb `
  --device cpu `
  --nllb-device cpu `
  --tts-engine piper `
  --tts-device cpu `
  --piper-model "C:\Stimmen\de_DE-thorsten-medium.onnx" `
  --piper-config "C:\Stimmen\de_DE-thorsten-medium.onnx.json"

Visualizza tutte le opzioni: python -m linguoai --help

Distribuire in modo sensato la potenza di calcolo

CPU e GPU non sono una decisione tutto o niente.

Whisper, NLLB e la voce locale possono essere posizionati separatamente. Quindi puoi iniziare in piccolo e mettere sullo GPU solo la parte che ne trae davvero beneficio.

"Automatico" controlla CUDA e altrimenti torna a CPU.

Importante: selezionando "GPU" non si installa automaticamente CUDA.
  • NLLB e Chatterbox

    È necessaria un'edizione CUDA corrispondente di PyTorch.

    Selezione PyTorch ↗
  • Faster-Whisper

    Inoltre richiede CUDA-12-cuBLAS e cuDNN 9 nel percorso di sistema.

  • Piper

    Utilizza il tempo di esecuzione ONNX: onnxruntime-gpu installare al posto dell'edizione CPU.

Riconoscimento più veloce facoltativo sulla CPU

Parakeet o Whisper?

Parakeet · 25 lingue

NVIDIA Parakeet v3 riconosce 25 lingue europee. L'adattatore facoltativo sherpa-onnx lavora in locale sulla CPU con quattro thread per impostazione predefinita.

Scheda del modello NVIDIA ↗

Whisper · versatile

Faster-Whisper resta l'opzione predefinita, con rilevamento automatico della lingua, una scelta più ampia di lingue ed elaborazione su CPU o GPU.

Faster-Whisper ↗

Il modello adattato di primeline è specializzato in tedesco. Per usarlo, scegli il profilo tedesco con un'esportazione ONNX compatibile; per più lingue europee, il profilo NVIDIA. Non è garantito un vantaggio di velocità o qualità senza un confronto sui tuoi file.

Configurare Parakeet

Installa il pacchetto facoltativo e prepara una cartella con un modello compatibile. I modelli non vengono scaricati automaticamente.

python -m pip install -e ".[parakeet]"
python -m linguoai --help

Usa la cartella completa del modello sherpa-onnx con encoder, decoder, joiner e file dei token. Per l'esportazione tedesca, conserva anche il file esterno dell'encoder se fa parte del modello.

Nell'app desktop e in Colab, scegli il motore di riconoscimento vocale, il profilo e la cartella del modello. Specifica esplicitamente la lingua di origine, così la traduzione riceve il codice lingua corretto. Parakeet trascrive; seguono la traduzione e la voce scelte.

La cassetta degli attrezzi completa

Tutte le funzioni in dettaglio.

File e ordini
  • Elabora un singolo video o tutti i video direttamente contenuti in una cartella.
  • Ingressi: MP4, MKV, MOV, AVI, WEBM e M4V; Edizioni: MP4, MKV o MOV.
  • Suggerimento di output automatico, nomi senza collisioni e sovrascrittura controllata.
  • Avanzamento per file, fase di lavoro corrente, cancellazione e registro tecnico.
  • Elaborazione singola e in batch: carica più video o inserisci i percorsi dei file su MyDrive, uno per riga. Carica i file Piper e la registrazione di riferimento oppure indica i loro percorsi MyDrive.
Trascrizione con Faster-Whisper
  • Modelli di tiny fino a quando large-v3, possiedono inoltre valori di modello.
  • Rileva automaticamente la lingua di origine o imposta come codice lingua.
  • CPU, NVIDIA-CUDA o selezione automatica; int8, float16 e float32 configurabili.
  • Sezioni audio sovrapposte, offset in tempo reale e pulizia dei segmenti duplicati.
  • Lunghezze dei pezzi, sovrapposizione e numero lavoratore tramite opzioni avanzate o CLI.
Traduzione e protezione del testo
  • NLLB-200 locale, Google Translate senza chiave, DeepL-SDK o Gemini.
  • Fallback opzionale solo dopo selezione esplicita, altrimenti verrà contattato solo un fornitore.
  • URL, indirizzi e-mail, valute, unità e percentuali sono protetti durante la traduzione.
  • Timeout, ripetizioni limitate e cache per sezioni di testo identiche.
  • Facoltativamente, Gemini corregge la trascrizione Whisper senza modificare gli ID o gli orari dei segmenti.
  • Possiedi modelli compatibili NLLB, revisioni fisse, codici FLORES, limiti batch e token.

Il modello NLLB-600M predefinito è sotto CC-BY-NC-4.0, è un modello di ricerca e non una traduzione di produzione certificata. Controlla sempre i risultati.

Timing, tono ed esportazione
  • Normalizza ogni clip su PCM mono a 48 kHz e posizionala con precisione al campione.
  • Accelera il discorso troppo lungo entro un limite configurabile.
  • Avvertimento in caso di accelerazione rapida; errore controllato invece di output incomprensibile.
  • Durata finale esatta, metadati/capitoli adottati e, se possibile, flusso video invariato.
  • Gruppo di risultati atomici dal nuovo video, SRT originale e traduzione SRT.
Dove vengono trattati i tuoi dati
  • NLLB · Piper · Chatterbox

    Dopo il download nel termine prescelto. In Colab ciò significa all'interno della VM temporanea di Google.

  • Google · DeepL · Gemini

    Ricevi sezioni di testo solo quando selezionate o come fallback esplicitamente attivato.

  • Edge TTS · gTTS

    Invia ogni battuta tradotta da doppiare al rispettivo servizio linguistico online.

  • Interfaccia web Gradio protetta con password casuale per sessione.
  • Cache del modello opzionale e copia atomica dei risultati in Google Drive.
  • I percorsi di guida rimangono all'interno di MyDrive; Drive non è condiviso come cartella di download pubblica.

I risultati temporanei non verranno pubblicati fino al completamento del video ed entrambi i sottotitoli. Interruzione, tentativi limitati, percorsi di destinazione protetti e chiavi API oscurate evitano spiacevoli sorprese.

Ciò che LinguoAI deliberatamente non promette

  • Il tempismo sincrono non è la sincronizzazione del movimento delle labbra; l'immagine non viene modificata.
  • La nuova traccia vocale sostituisce completamente il suono originale. Musica, atmosfera e suoni attualmente non vengono adottati.
  • Nessun riconoscimento degli oratori e nessuna assegnazione automatica di più altoparlanti.
  • Controlla sempre la trascrizione, la traduzione, la pronuncia e la somiglianza vocale prima di pubblicare.
  • Colab-GPU, la durata della sessione e il completamento di lavori di grandi dimensioni non sono garantiti.

FACOLTATIVO

Il tuo indirizzo con Cloudflare Tunnel.

Con SHARE_PROVIDER = "gradio" ricevi automaticamente un link dinamico. Google Drive è facoltativo.

Cloudflare facoltativo

Solo per un indirizzo fisso personale: configura un Cloudflare Tunnel con nome, il tuo dominio e il servizio http://127.0.0.1:7860. Non è un server LinguoAI fornito al pubblico.

Nel Notebook imposta SHARE_PROVIDER su "cloudflare", inserisci il tuo nome host in CLOUDFLARE_TUNNEL_HOSTNAME e salva CLOUDFLARE_TUNNEL_TOKEN come Colab Secret. Non pubblicare mai il token.

Cloudflare: 95 MB per caricamento per impostazione predefinita. Gradio: fino a 5 GB per file. Usa Google Drive per i video grandi. I link temporanei trycloudflare.com non vengono usati perché non supportano SSE.
