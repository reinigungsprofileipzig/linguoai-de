Uno strumento, un processo chiaro

Prenditi cura della lingua. LinguoAI si prende cura del resto.

Nessuna magia oscura con un clic: ogni componente importante rimane selezionabile - dalla trascrizione al traduttore fino alla voce e al dispositivo utilizzato.

Cosa può fare LinguoAI

Tutto per la nuova versione linguistica.

L'interfaccia desktop, la versione CLI e Colab utilizzano la stessa robusta elaborazione in background.

01

Riconoscere con precisione la lingua

Faster-Whisper elabora la traccia audio in sezioni sovrapposte e conserva i timestamp in tempo reale. Puoi impostare tu stesso il modello Whisper, CPU/GPU e il formato di calcolo.

  • Faster-Whisper
  • Riconoscimento vocale automatico o fisso
  • File e cartelle
02

Traduci in modo appropriato

Scegli Google, DeepL, Gemini o il locale NLLB-200. Un secondo servizio verrà utilizzato solo se lo attivi esplicitamente come fallback.

  • NLLB localmente su CPU o CUDA
  • Possiedi modelli NLLB compatibili
  • Ottimizzazione del testo Gemini opzionale
03

Scegli la voce giusta

Voce online, modello ONNX locale o registrazione di riferimento autorizzata: Edge, gTTS, Piper e Chatterbox sono liberamente selezionabili per ordine.

Confronta le voci →
04

Rimani puntuale

Ogni clip vocale viene normalizzata, adattata alla sua finestra temporale e classificata con precisione campione. Le frasi successive non vengono semplicemente spostate.

  • PCM mono a 48kHz
  • Regolazione del tempo limitata
  • Finale multimediale esatto
05

Sottotitoli inclusi

Per ogni video finito viene creato un file SRT con il testo originale ed un secondo con la traduzione. Ciò significa che il risultato può essere utilizzato in modo flessibile.

  • Video
  • SRT originale
  • Tradotto SRT
06

Lavora in modo sicuro e comprensibile

I risultati temporanei non verranno pubblicati fino al completamento del video ed entrambi i sottotitoli. Interruzione, tentativi limitati, percorsi di destinazione protetti e chiavi API oscurate evitano spiacevoli sorprese.

  • Annulla
  • Rollback
  • Timeout
  • Nessuna chiave nei log

Usa la tua voce in modo responsabile

Per Chatterbox, la conferma che è possibile utilizzare la voce è obbligatoria. Utilizza la tua registrazione o ottieni un'autorizzazione esplicita. L'output contiene anche una filigrana PerTh incorporata.

Buon tiro di riferimento 6-10 secondi, una persona, poco riverbero, nessuna musica o rumore di fondo.
Primo lancio dello Chatterbox Download del modello da circa 3,7 GB; CPU è possibile, ma molto lento per i video più lunghi.
Nota Windows L'installazione nativa è sperimentale; Colab o Linux sono più affidabili per i problemi dei pacchetti audio.

Dove vengono trattati i tuoi dati

“Locale” e “online” rimangono chiaramente separati.

LOCALENLLB · Piper · Chatterbox

Dopo il download nel termine prescelto. In Colab ciò significa all'interno della VM temporanea di Google.

IN LINEAGoogle · DeepL · Gemini

Ricevi sezioni di testo solo quando selezionate o come fallback esplicitamente attivato.

IN LINEAEdge TTS · gTTS

Invia ogni battuta tradotta da doppiare al rispettivo servizio linguistico online.

Le voci di riferimento contengono caratteristiche biometricamente sensibili. La conferma in LinguoAI non sostituisce il consenso; Il motore Piper e il modello vocale possono anche avere licenze separate.

Apri interfaccia

Scegli video, destinazione, traduttore e voce. Il controllo del sistema ti mostra direttamente se manca ancora un pacchetto o un modello.

PowerShell · Configurazione di base 
# FFmpeg einmalig installieren
winget install --id Gyan.FFmpeg --exact

# Im Projektordner ausführen
cd "C:\Pfad\zu\LinguoAI-2.2.1"
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1

python -m pip install --upgrade pip
python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
python -m pip install -e ".[desktop]"
ffmpeg -version
ffprobe -version
python -m linguoai

L'esempio imposta deliberatamente la versione CPU. Per NVIDIA selezionare prima il comando appropriato in Procedura guidata di installazione PyTorch. Edge TTS e gTTS sono già inclusi. Per Piper si installa .[desktop,piper], per Chatterbox nel proprio ambiente .[desktop,voice-clone].

gTTS / Utilizza Google Voice +

gTTS è incluso nel pacchetto base. Può essere installato singolarmente in questo modo:

python -m pip install gTTS
python -m linguoai -i quelle.mp4 -o ziel.mp4 -l de --tts-engine gtts
Aggiungi Piper localmente +

Installa nello stesso ambiente virtuale e quindi carica una voce adatta:

python -m pip install -e ".[desktop,piper]"
New-Item -ItemType Directory -Force ".\Stimmen"
python -m piper.download_voices --download-dir ".\Stimmen" de_DE-thorsten-medium
Voce di riferimento propria con Chatterbox +

A causa delle dipendenze audio/torcia, si consiglia un ambiente Python-3.11 dedicato:

py -3.11 -m venv .venv-chatterbox
.\.venv-chatterbox\Scripts\Activate.ps1

Un'attività locale completa

Questo esempio si traduce localmente in NLLB e utilizza un modello Piper. Per l'automazione sono disponibili le stesse impostazioni dello GUI.

  • Singolo video o intera cartella
  • Propri output e percorsi del modello

PowerShell · Piper localmente 
python -m linguoai `
  --input "C:\Videos\quelle.mp4" `
  --output "C:\Videos\quelle.de.mp4" `
  --language de `
  --service nllb `
  --device cpu `
  --nllb-device cpu `
  --tts-engine piper `
  --tts-device cpu `
  --piper-model "C:\Stimmen\thorsten.onnx" `
  --piper-config "C:\Stimmen\thorsten.onnx.json"

Visualizza tutte le opzioni: python -m linguoai --help

Distribuire in modo sensato la potenza di calcolo

CPU e GPU non sono una decisione tutto o niente.

Whisper, NLLB e la voce locale possono essere posizionati separatamente. Quindi puoi iniziare in piccolo e mettere sullo GPU solo la parte che ne trae davvero beneficio.

La cassetta degli attrezzi completa

Tutte le funzioni in dettaglio.

Non è necessario conoscere tutte le impostazioni per iniziare. Se in seguito avrai bisogno di maggiore controllo, qui troverai la portata completa, senza promesse nascoste.

01File e ordini+
  • Elabora un singolo video o tutti i video direttamente contenuti in una cartella.
  • Ingressi: MP4, MKV, MOV, AVI, WEBM e M4V; Edizioni: MP4, MKV o MOV.
  • Suggerimento di output automatico, nomi senza collisioni e sovrascrittura controllata.
  • Avanzamento per file, fase di lavoro corrente, cancellazione e registro tecnico.

Le cartelle non vengono cercate deliberatamente in modo ricorsivo. In Colab viene eseguito un video per ordine.

02Trascrizione con Faster-Whisper+
  • Modelli di tiny fino a quando large-v3, possiedono inoltre valori di modello.
  • Rileva automaticamente la lingua di origine o imposta come codice lingua.
  • CPU, NVIDIA-CUDA o selezione automatica; int8, float16 e float32 configurabili.
  • Sezioni audio sovrapposte, offset in tempo reale e pulizia dei segmenti duplicati.
  • Lunghezze dei pezzi, sovrapposizione e numero lavoratore tramite opzioni avanzate o CLI.
03Traduzione e protezione del testo+
  • NLLB-200 locale, Google Translate senza chiave, DeepL-SDK o Gemini.
  • Fallback opzionale solo dopo selezione esplicita, altrimenti verrà contattato solo un fornitore.
  • URL, indirizzi e-mail, valute, unità e percentuali sono protetti durante la traduzione.
  • Timeout, ripetizioni limitate e cache per sezioni di testo identiche.
  • Facoltativamente, Gemini corregge la trascrizione Whisper senza modificare gli ID o gli orari dei segmenti.
  • Possiedi modelli compatibili NLLB, revisioni fisse, codici FLORES, limiti batch e token.

Il modello NLLB-600M predefinito è sotto CC-BY-NC-4.0, è un modello di ricerca e non una traduzione di produzione certificata. Controlla sempre i risultati.

04Edge, gTTS, Piper e Chatterbox+
  • Edge: voce predefinita automatica o proprio ID vocale Edge completo.
  • gTTS: Google Translate Sintesi vocale con lingua di destinazione automatica o codice lingua.
  • Piper: ONNX più JSON corrispondente, ID altoparlante opzionale e velocità di conversazione regolabile.
  • Chatterbox V2: controllo dei riferimenti, stampa, forza CFG, conferma dei diritti e filigrana.
  • Esegui il motore locale su CPU, CUDA o automaticamente con il fallback CPU.
  • I modelli vengono caricati solo per il motore selezionato e poi rilasciati nuovamente.

gTTS e Edge sono servizi online e non cloni vocali. LinguoAI carica i modelli Piper ma non li addestra. Viene utilizzato un voto per ordine. Chatterbox rifiuta i riferimenti inferiori a 0,5 o superiori a 60 secondi e praticamente consiglia 6-10 secondi.

05Timing, tono ed esportazione+
  • Normalizza ogni clip su PCM mono a 48 kHz e posizionala con precisione al campione.
  • Accelera il discorso troppo lungo entro un limite configurabile.
  • Avvertimento in caso di accelerazione rapida; errore controllato invece di output incomprensibile.
  • Durata finale esatta, metadati/capitoli adottati e, se possibile, flusso video invariato.
  • Gruppo di risultati atomici dal nuovo video, SRT originale e traduzione SRT.
06Interfaccia desktop e CLI+
  • Tre schede GUI: Home, Avanzate e Log; oltre alla modalità luce e buio.
  • Campi dinamici, controllo di sistema, etichettatura locale/online e informativa sulla privacy.
  • Apri direttamente il video risultato o la cartella di output; Copia o svuota il registro.
  • Tastiera: Strg+O, Strg+Enter e Esc.
  • CLI per lavori di file/cartelle con tutte le opzioni di dispositivo, modello, timeout e debug.
07Colab, Guida e percorsi sicuri+
  • Interfaccia web Gradio protetta con password casuale per sessione.
  • Elaborazione singola e in batch: carica più video o inserisci i percorsi dei file su MyDrive, uno per riga. Carica i file Piper e la registrazione di riferimento oppure indica i loro percorsi MyDrive.
  • Cache del modello opzionale e copia atomica dei risultati in Google Drive.
  • Video finale ed entrambi i file SRT per ogni attività; 5 GB per caricamento Gradio o, per impostazione predefinita, 95 MB tramite Cloudflare Tunnel facoltativo.
  • I percorsi di guida rimangono all'interno di MyDrive; Drive non è condiviso come cartella di download pubblica.
08Ciò che LinguoAI deliberatamente non promette+
  • Il tempismo sincrono non è la sincronizzazione del movimento delle labbra; l'immagine non viene modificata.
  • La nuova traccia vocale sostituisce completamente il suono originale. Musica, atmosfera e suoni attualmente non vengono adottati.
  • Nessun riconoscimento degli oratori e nessuna assegnazione automatica di più altoparlanti.
  • Controlla sempre la trascrizione, la traduzione, la pronuncia e la somiglianza vocale prima di pubblicare.
  • Colab-GPU, la durata della sessione e il completamento di lavori di grandi dimensioni non sono garantiti.

Ancora incerto?

Domande frequenti, risposte chiare.

Per il primo tentativo sono sufficienti un breve video, Edge TTS e le impostazioni standard.

Posso utilizzare LinguoAI senza installazione?+

Sì. Aprire lo Notebook preparato utilizzando il pulsante “Apri in Colab” e selezionare “Runtime → Esegui tutto”. Lo Notebook scarica automaticamente il codice sorgente ZIP tramite l'indirizzo di download protetto su questo sito Web. Tutto ciò di cui hai bisogno è un account Google; il collegamento Gradio funziona finché è attiva la sessione Colab.

LinguoAI può usare la mia voce?+

Sì. Chatterbox adotta una voce autorizzata da una breve registrazione di riferimento. In alternativa, puoi utilizzare Piper per caricare il tuo modello ONNX che è già stato addestrato. Edge TTS offre solo parti di catalogo finite; gTTS utilizza i codici vocali di Google, ma non la propria copia vocale.

Il programma viene eseguito completamente localmente?+

Con Faster-Whisper, NLLB e Piper o Chatterbox, l'elaborazione viene eseguita nel runtime selezionato dopo il download iniziale del modello. Sul desktop, questo è il tuo computer; in Colab è la VM temporanea di Google. Edge TTS, gTTS, Google Translate, DeepL e Gemini sono servizi online.

Ho bisogno di una scheda grafica potente?+

No. Whisper, NLLB e Piper funzionano sullo CPU. Anche Chatterbox funziona, ma è notevolmente più lento. Uno NVIDIA-GPU è utile per progetti più lunghi.

Cosa ottengo alla fine?+

Un video appena doppiato e due file SRT: uno con il testo originale riconosciuto e uno con la traduzione. Il video sorgente rimane invariato.

Posso caricare file direttamente da Google Drive?+

Sì, nell'interfaccia Colab. È possibile specificare un percorso relativo sicuro all'interno di MyDrive e riscrivere i risultati in una cartella Drive.

Quali lingue supporta la tua voce di riferimento?+

Chatterbox Multilingual V2 supporta 23 lingue di base tra cui tedesco, inglese, francese, spagnolo, italiano, portoghese, polacco, turco, giapponese, coreano e cinese. Piper dipende dalla lingua del modello selezionato. gTTS supporta molti codici linguistici di Google Translate, ma non voci di riferimento.
