One tool, one clear process

You take care of the language. LinguoAI takes care of the rest.

No obscure one-click magic: every important component remains selectable - from the transcription to the translator to the voice and the device used.

What LinguoAI can do

Everything for the new language version.

The desktop interface, the CLI and the Colab version use the same robust background processing.

01

Recognize language precisely

Faster-Whisper processes the audio track in overlapping sections and retains real time stamps. You set the Whisper model, CPU/GPU and calculation format yourself.

  • Faster-Whisper
  • Speech recognition automatic or fixed
  • File & Folder
02

Translate appropriately

Choose Google, DeepL, Gemini or the local NLLB-200. A second service will only be used if you explicitly activate it as a fallback.

  • NLLB locally on CPU or CUDA
  • Own compatible NLLB models
  • Optional Gemini text optimization
03

Choose the right voice

Online voice, local ONNX model or an authorized reference recording: Edge, gTTS, Piper and Chatterbox are freely selectable per order.

Compare voices →
04

Stay on timing

Each speech clip is normalized, adapted to its time window and classified with sample accuracy. Subsequent sentences are not simply moved.

  • 48kHz mono PCM
  • Limited tempo adjustment
  • Exact media ending
05

Subtitles included

For each finished video, a SRT file is created with the original text and a second with the translation. This means the result can be used flexibly.

  • Video
  • Original SRT
  • Translated SRT
06

Work safely and comprehensibly

Temporary results will not be published until video and both subtitles are complete. Abort, limited retries, protected destination paths and redacted API keys avoid unpleasant surprises.

  • Cancel
  • Rollback
  • Timeouts
  • No keys in logs

This is how LinguoAI works

Six steps. A finished video.

In the progress area you can see what is currently happening at any time. The individual models are only loaded when they are actually needed.

  1. 01
    Read videoFFmpeg checks picture, sound and duration.
  2. 02
    Extract soundThe source is prepared as 16 kHz audio.
  3. 03
    TranscribeWhisper recognizes text and time windows.
  4. 04
    TranslateThe selected service broadcasts each cue.
  5. 05
    DubYour TTS engine generates the new voice.
  6. 06
    MergeVideo, voice track and SRTs are released.

Where your data is processed

“Local” and “online” remain clearly separated.

LOCALNLLB · Piper · Chatterbox

After downloading in your chosen term. In Colab that means inside the temporary Google VM.

ONLINEGoogle · DeepL · Gemini

Only receive text sections when selected or as an explicitly activated fallback.

ONLINEEdge TTS · gTTS

Send each translated cue to be dubbed to the respective online language service.

Reference voices contain biometrically sensitive features. The confirmation in LinguoAI does not replace consent; Piper engine and voice model can also have separate licenses.

You need Python 3.10 or newer as well as FFmpeg and ffprobe. Python 3.11 is recommended for Chatterbox. Then open a new PowerShell.

The virtual environment keeps LinguoAI and its packages neatly separated from the rest of the system.

Open interface

PowerShell · Basic setup 
# FFmpeg einmalig installieren
winget install --id Gyan.FFmpeg --exact

# Im Projektordner ausführen
cd "C:\Pfad\zu\LinguoAI-2.2.1"
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1

python -m pip install --upgrade pip
python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
python -m pip install -e ".[desktop]"
ffmpeg -version
ffprobe -version
python -m linguoai

The example deliberately sets up the CPU version. For NVIDIA you first select the appropriate command in PyTorch installation wizard. Edge TTS and gTTS are already included. For Piper you install .[desktop,piper], for Chatterbox in its own environment .[desktop,voice-clone].

gTTS / Use Google Voice +

gTTS is included in the basic package. It can be installed individually like this:

python -m pip install gTTS

A complete local job

This example translates locally to NLLB and uses a Piper model. The same settings as in the GUI are available for automation.

  • Single video or entire folder
  • Own output and model paths
  • Explicit CPU/GPU association
  • Quiet or verbose debug mode
PowerShell · Piper locally 
python -m linguoai `
  --input "C:\Videos\quelle.mp4" `
  --output "C:\Videos\quelle.de.mp4" `
  --language de `
  --service nllb `
  --device cpu `
  --nllb-device cpu `
  --tts-engine piper `
  --tts-device cpu `
  --piper-model "C:\Stimmen\thorsten.onnx" `
  --piper-config "C:\Stimmen\thorsten.onnx.json"

View all options: python -m linguoai --help

The complete toolbox

All functions in detail.

You don't need to know every setting to get started. If you need more control later, you'll find the full scope here - without any hidden promises.

01Files and orders+
  • Process a single video or all videos directly contained in a folder.
  • Inputs: MP4, MKV, MOV, AVI, WEBM and M4V; Editions: MP4, MKV or MOV.
  • Automatic output suggestion, collision-free names and controlled overwriting.
  • Progress per file, current work step, cancellation and technical log.

Folders are deliberately not searched recursively. In Colab one video runs per order.

02Transcription with Faster-Whisper+
  • Models of tiny until large-v3, additionally own model values.
  • Automatically detect source language or set as language code.
  • CPU, NVIDIA-CUDA or automatic selection; int8, float16 and float32 configurable.
  • Overlapping audio sections, true time offsets and duplicate segment cleanup.
  • Chunk lengths, overlap and worker number via advanced options or CLI.
03Translation and text protection+
  • NLLB-200 local, Google Translate without key, DeepL-SDK or Gemini.
  • Optional fallback only after explicit selection - otherwise only one provider will be contacted.
  • URLs, email addresses, currencies, units and percentages are protected during translation.
  • Timeouts, limited repeats and cache for identical text sections.
  • Optionally, Gemini corrects the Whisper transcript without changing segment IDs or times.
  • Own NLLB compatible models, fixed revisions, FLORES codes, batch and token limits.

The default NLLB-600M model is under CC-BY-NC-4.0, is a research model and not a certified production translation. Always check results.

04Edge, gTTS, Piper and Chatterbox+
  • Edge: automatic default voice or own full Edge voice ID.
  • gTTS: Google Translate Text-to-speech with automatic target language or language code.
  • Piper: ONNX plus matching JSON, optional speaker ID and adjustable speaking rate.
  • Chatterbox V2: Reference checking, printout, CFG strength, rights confirmation and watermark.
  • Run local engine on CPU, CUDA or automatically with CPU fallback.
  • Models are only loaded for the selected engine and then released again.

gTTS and Edge are online services and not voice clones. LinguoAI loads Piper models but does not train them. One vote is used per order. Chatterbox rejects references below 0.5 or above 60 seconds and practically recommends 6-10 seconds.

05Timing, tone and export+
  • Normalize each clip to 48 kHz mono PCM and position it with sample accuracy.
  • Speed up speech that is too long within a configurable limit.
  • Warning when accelerating quickly; controlled error instead of incomprehensible output.
  • Exact end duration, adopted metadata/chapters and, if possible, unchanged video stream.
  • Atomic result group from new video, original SRT and translation SRT.
06Desktop interface and CLI+
  • Three GUI tabs: Home, Advanced and Log; plus light and dark mode.
  • Dynamic fields, system check, local/online labeling and data protection notice.
  • Open result video or output folder directly; Copy or empty log.
  • Keyboard: Strg+O, Strg+Enter and Esc.
  • CLI for file/folder jobs with all device, model, timeout and debug options.
07Colab, Drive and safe paths+
  • Protected Gradio web interface with random password per session.
  • Single and batch processing: upload multiple videos or enter MyDrive file paths, one per line. Upload Piper files and a reference recording, or provide their MyDrive paths.
  • Optional model cache and atomic result copy in Google Drive.
  • Output video and both SRT files for each job; 5 GB per Gradio upload, or 95 MB by default through the optional Cloudflare Tunnel.
  • Drive paths remain within MyDrive; Drive is not shared as a public download folder.
08What LinguoAI deliberately does not promise+
  • Synchronous timing is not lip movement synchronization; the image is not changed.
  • The new voice track completely replaces the original sound. Music, atmosphere and sounds are currently not being adopted.
  • No speaker recognition and no automatic multi-speaker assignment.
  • Always check transcript, translation, pronunciation and voice similarity before publishing.
  • Colab-GPU, session length and completion of large jobs are not guaranteed.

Still unsure?

Frequently asked questions, clearly answered.

For the first attempt, a short video, Edge TTS and the standard settings are sufficient.

Can I use LinguoAI without installation?+

Yes. Open the prepared Notebook using the “Open in Colab” button and select “Runtime → Run all”. The Notebook automatically downloads the source code ZIP via the secured download address on this website. All you need is a Google account; the Gradio link works as long as the Colab session is active.

Can LinguoAI use my own voice?+

Yes. Chatterbox adopts an authorized voice from a short reference recording. Alternatively, you can use Piper to load your own ONNX model that has already been trained. Edge TTS only offers finished catalog parts; gTTS uses Google voice codes, but not its own voice copy.

Does the program run completely locally?+

With Faster-Whisper, NLLB and Piper or Chatterbox, processing runs in the selected runtime after the initial model downloads. On the desktop, this is your computer; in Colab it is the temporary Google VM. Edge TTS, gTTS, Google Translate, DeepL and Gemini are online services.

Do I need a powerful graphics card?+

No. Whisper, NLLB and Piper work on the CPU. Chatterbox also runs, but is significantly slower. A NVIDIA-GPU is helpful for longer projects.

What do I get in the end?+

A newly dubbed video and two SRT files: one with the recognized original text and one with the translation. The source video itself remains unchanged.

Can I load files directly from Google Drive?+

Yes, in the Colab interface. You can specify a safe relative path within MyDrive and have results written back to a Drive folder.

Which languages does your own reference voice support?+

Chatterbox Multilingual V2 supports 23 basic languages including German, English, French, Spanish, Italian, Portuguese, Polish, Turkish, Japanese, Korean and Chinese. Piper depends on the language of the selected model. gTTS supports many Google Translate language codes, but not reference voices.
