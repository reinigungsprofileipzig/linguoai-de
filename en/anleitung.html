Windows & Linux

Install locally

You need Python 3.10 or newer as well as FFmpeg and ffprobe. Python 3.11 is recommended for Chatterbox. Then open a new PowerShell.

Load version 2.2.1 ↓

Download, unpack completely and then follow the local instructions.

PowerShell · Basic setup 
# FFmpeg einmalig installieren
winget install --id Gyan.FFmpeg --exact

# Im entpackten Projektordner ausführen; Pfad anpassen
cd "C:\Pfad\zu\LinguoAI-2.2.1"
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1

python -m pip install --upgrade pip
python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
python -m pip install -e ".[desktop]"
ffmpeg -version
ffprobe -version
python -m linguoai

The example deliberately sets up the CPU version. For NVIDIA you first select the appropriate command in PyTorch installation wizard. Edge TTS and gTTS are already included. For Piper you install .[desktop,piper], for Chatterbox in its own environment .[desktop,voice-clone].

Four ways to get a voice track

Compare voices

“Own voice” can mean different things. This comparison will help you make the right choice.

Edge TTS

The easy way to get started with ready-made voices from the Microsoft catalog.

Online · No, catalog voice

gTTS

Fast Google Voice via Google Translate Text-to-Speech with voice code.

Online · No, language code

Piper

Fast local output with an existing or self-trained ONNX model.

Local · CPU, optional CUDA

Chatterbox V2

Adopts vocal character and manner of speaking from a short, clean recording.

Reference voice · GPU recommended

Add Piper locally

Install in the same virtual environment and then load a suitable voice:

python -m pip install -e ".[desktop,piper]"
New-Item -ItemType Directory -Force ".\Stimmen"
python -m piper.download_voices --download-dir ".\Stimmen" de_DE-thorsten-medium

Piper: ONNX plus matching JSON, optional speaker ID and adjustable speaking rate.

Own reference voice with Chatterbox

Due to audio/torch dependencies, a dedicated Python-3.11 environment is recommended:

py -3.11 -m venv .venv-chatterbox
.\.venv-chatterbox\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -e ".[desktop,voice-clone]"
python -m linguoai
  • 6-10 seconds, one person, little reverb, no music or background noise.
  • Approximately 3.7GB model download; CPU is possible, but very slow for longer videos.
  • The native installation is experimental; Colab or Linux is more reliable for audio packet problems.
Use your voice responsibly

For Chatterbox, confirmation that you can use the voice is mandatory. Use your own recording or get explicit permission. The output also contains an embedded PerTh watermark.

Reference voices contain biometrically sensitive features. The confirmation in LinguoAI does not replace consent; Piper engine and voice model can also have separate licenses.

For repeatable processes

Command line

This example translates locally to NLLB and uses a Piper model. The same settings as in the GUI are available for automation.

Own output and model paths

PowerShell · Piper locally 
python -m linguoai `
  --input "C:\Videos\quelle.mp4" `
  --output "C:\Videos\quelle.de.mp4" `
  --language de `
  --service nllb `
  --device cpu `
  --nllb-device cpu `
  --tts-engine piper `
  --tts-device cpu `
  --piper-model "C:\Stimmen\de_DE-thorsten-medium.onnx" `
  --piper-config "C:\Stimmen\de_DE-thorsten-medium.onnx.json"

View all options: python -m linguoai --help

Distribute computing power sensibly

CPU and GPU are not an all-or-nothing decision.

Whisper, NLLB and the local voice can be placed separately. So you can start small and only put the part on the GPU that really benefits from it.

“Automatic” checks CUDA and otherwise falls back to CPU.

Important: Selecting “GPU” does not automatically install CUDA.
  • NLLB & Chatterbox

    Need a matching CUDA edition of PyTorch.

    PyTorch selection ↗
  • Faster-Whisper

    Additionally requires CUDA-12-cuBLAS and cuDNN 9 in the system path.

  • Piper

    Uses ONNX Runtime: onnxruntime-gpu install instead of the CPU edition.

Optional faster recognition on the CPU

Parakeet or Whisper?

Parakeet · 25 languages

NVIDIA Parakeet v3 recognizes 25 European languages. The optional sherpa-onnx adapter runs locally on the CPU with four threads by default.

NVIDIA model card ↗

Whisper · versatile

Faster-Whisper remains the default, with automatic language detection, a broader language selection, and CPU or GPU processing.

Faster-Whisper ↗

The primeline fine-tune specializes in German. Use the German profile with a compatible ONNX export for it; choose the NVIDIA profile for multiple European languages. A speed or quality advantage is not guaranteed without comparison using your own files.

Set up Parakeet

Install the optional package and provide a compatible model folder. Models are not downloaded automatically.

python -m pip install -e ".[parakeet]"
python -m linguoai --help

Use the complete sherpa-onnx model folder with encoder, decoder, joiner, and token file. For the German export, also keep the external encoder file if it is part of the model.

In the desktop app and Colab, select the speech recognition engine, profile, and model folder. Specify the source language explicitly so that translation receives the correct language code. Parakeet transcribes; the selected translation and voice follow afterwards.

Upload → processing → download

Work in the browser.

The Colab web interface already accepts uploads and Google Drive file paths. It processes videos on the active Colab machine and offers the video and subtitles for download. You can also save the results to your Drive.

Next step: your own server running continuously

Technically possible: the website accepts an upload, a queue manages the job, and a separate worker downloads the file, transcribes and translates the speech, and saves the result. The website then offers a protected download.

Google Drive can serve as private temporary storage. Access through user OAuth or a Workspace Shared Drive is required; a service account has no MyDrive storage of its own. Status and job distribution belong in a separate database.

This server service has not been set up yet. Until then, the web interface starts through an active Colab session.

The complete toolbox

All functions in detail.

Files and orders
  • Process a single video or all videos directly contained in a folder.
  • Inputs: MP4, MKV, MOV, AVI, WEBM and M4V; Editions: MP4, MKV or MOV.
  • Automatic output suggestion, collision-free names and controlled overwriting.
  • Progress per file, current work step, cancellation and technical log.
  • Single and batch processing: upload multiple videos or enter MyDrive file paths, one per line. Upload Piper files and a reference recording, or provide their MyDrive paths.
Transcription with Faster-Whisper
  • Models of tiny until large-v3, additionally own model values.
  • Automatically detect source language or set as language code.
  • CPU, NVIDIA-CUDA or automatic selection; int8, float16 and float32 configurable.
  • Overlapping audio sections, true time offsets and duplicate segment cleanup.
  • Chunk lengths, overlap and worker number via advanced options or CLI.
Translation and text protection
  • NLLB-200 local, Google Translate without key, DeepL-SDK or Gemini.
  • Optional fallback only after explicit selection - otherwise only one provider will be contacted.
  • URLs, email addresses, currencies, units and percentages are protected during translation.
  • Timeouts, limited repeats and cache for identical text sections.
  • Optionally, Gemini corrects the Whisper transcript without changing segment IDs or times.
  • Own NLLB compatible models, fixed revisions, FLORES codes, batch and token limits.

The default NLLB-600M model is under CC-BY-NC-4.0, is a research model and not a certified production translation. Always check results.

Timing, tone and export
  • Normalize each clip to 48 kHz mono PCM and position it with sample accuracy.
  • Speed up speech that is too long within a configurable limit.
  • Warning when accelerating quickly; controlled error instead of incomprehensible output.
  • Exact end duration, adopted metadata/chapters and, if possible, unchanged video stream.
  • Atomic result group from new video, original SRT and translation SRT.
Where your data is processed
  • NLLB · Piper · Chatterbox

    After downloading in your chosen term. In Colab that means inside the temporary Google VM.

  • Google · DeepL · Gemini

    Only receive text sections when selected or as an explicitly activated fallback.

  • Edge TTS · gTTS

    Send each translated cue to be dubbed to the respective online language service.

  • Protected Gradio web interface with random password per session.
  • Optional model cache and atomic result copy in Google Drive.
  • Drive paths remain within MyDrive; Drive is not shared as a public download folder.

Temporary results will not be published until video and both subtitles are complete. Abort, limited retries, protected destination paths and redacted API keys avoid unpleasant surprises.

What LinguoAI deliberately does not promise

  • Synchronous timing is not lip movement synchronization; the image is not changed.
  • The new voice track completely replaces the original sound. Music, atmosphere and sounds are currently not being adopted.
  • No speaker recognition and no automatic multi-speaker assignment.
  • Always check transcript, translation, pronunciation and voice similarity before publishing.
  • Colab-GPU, session length and completion of large jobs are not guaranteed.

OPTIONAL

Your own address with Cloudflare Tunnel.

With SHARE_PROVIDER = "gradio", you automatically get a dynamic link. Google Drive is optional.

Optional Cloudflare

Only for your own fixed address: configure a named Cloudflare Tunnel with your domain and the service http://127.0.0.1:7860. This is not a publicly provided LinguoAI server.

In the Notebook, set SHARE_PROVIDER to "cloudflare", enter your hostname in CLOUDFLARE_TUNNEL_HOSTNAME and store CLOUDFLARE_TUNNEL_TOKEN as a Colab Secret. Never publish the token.

Cloudflare: 95 MB per upload by default. Gradio: up to 5 GB per file. Use Google Drive for large videos. Temporary trycloudflare.com links are not used because they do not support SSE.
