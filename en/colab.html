Without permanent installation

Start LinguoAI in Google Colab.

First download the prepared Notebook directly from linguoai.de. Then open Google Colab and upload the Notebook file. The project ZIP is automatically downloaded from linguoai.de.

1. Download Notebook ↓ 2. Open Google Colab ↗

The downloaded file is called LinguoAI_Colab.ipynb. Keep it as is and select this exact file when uploading to Colab.

That's what you need
  • a Google account
  • a short test video
  • an active internet connection

A Colab GPU is optional. The dynamic Gradio link needs no Cloudflare account, custom domain or tunnel token.

Step by step

This is how you open the Notebook.

  1. 01
    Download Notebook

    Click on “Download Notebook” above. The file usually ends up in the Downloads folder.

  2. 02
    Open Google Colab

    Sign in with your Google account and select “Upload” in the home window.

  3. 03
    Upload file

    Select LinguoAI_Colab.ipynb in your Downloads folder and open it.

  4. 04
    Run Notebook

    In the Colab menu, choose “Runtime → Run all”. One self-checking code cell installs LinguoAI and starts the interface.

  5. 05
    Open the Gradio web interface

    Open the generated Gradio link and sign in with the displayed credentials. Upload one or more videos, or enter Google Drive file paths, one per line.

FIRST TEST

You can leave these settings.

PROJECT_SOURCE = "download_zip" automatically downloads LinguoAI from linguoai.de. With LOCAL_TTS_EXTRA = "none", Edge TTS and gTTS work without a large additional voice package.

With SHARE_PROVIDER = "gradio", you automatically get a dynamic link. Google Drive is optional.

IMPORTANT

Colab sessions are temporary.

Download the finished videos and both SRT files for each job, or save them to Google Drive. Files under /content and the Gradio link disappear when the session ends.

OPTIONAL

Your own address with Cloudflare Tunnel.

Only for your own fixed address: configure a named Cloudflare Tunnel with your domain and the service http://127.0.0.1:7860. This is not a publicly provided LinguoAI server.

In the Notebook, set SHARE_PROVIDER to "cloudflare", enter your hostname in CLOUDFLARE_TUNNEL_HOSTNAME and store CLOUDFLARE_TUNNEL_TOKEN as a Colab Secret. Never publish the token.

Cloudflare: 95 MB per upload by default. Gradio: up to 5 GB per file. Use Google Drive for large videos. Temporary trycloudflare.com links are not used because they do not support SSE.
