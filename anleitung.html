Windows & Linux

Lokal installieren

Du brauchst Python 3.10 oder neuer sowie FFmpeg und ffprobe. Für Chatterbox wird Python 3.11 empfohlen. Öffne danach eine neue PowerShell.

Version 2.2.1 laden ↓

Herunterladen, vollständig entpacken und anschließend die lokale Anleitung ausführen.

PowerShell · Basiseinrichtung 
# FFmpeg einmalig installieren
winget install --id Gyan.FFmpeg --exact

# Im entpackten Projektordner ausführen; Pfad anpassen
cd "C:\Pfad\zu\LinguoAI-2.2.1"
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1

python -m pip install --upgrade pip
python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
python -m pip install -e ".[desktop]"
ffmpeg -version
ffprobe -version
python -m linguoai

Das Beispiel richtet bewusst die CPU-Version ein. Für NVIDIA wählst du zuerst den passenden Befehl im PyTorch-Installationsassistenten. Edge TTS und gTTS sind bereits dabei. Für Piper installierst du .[desktop,piper], für Chatterbox in einer eigenen Umgebung .[desktop,voice-clone].

  2. Sprachen festlegen

    Zielsprache wählen; die Quellsprache darf automatisch erkannt werden.

  3. Übersetzer wählen

    Für lokal: NLLB. Für einen schnellen Test: Google. DeepL/Gemini brauchen ihren Schlüssel; die separate Gemini-Optimierung ebenfalls.

  4. Stimme bestimmen

    Edge oder gTTS sofort testen; Piper beziehungsweise Chatterbox richtest du unter „Erweitert“ ein.

  5. Verarbeitung starten

    Fortschritt beobachten; am Ende Video und beide SRT-Dateien direkt öffnen.

Vier Wege zur Sprachspur

Stimmen vergleichen

„Eigene Stimme“ kann Unterschiedliches bedeuten. Dieser Vergleich hilft dir bei der richtigen Wahl.

Edge TTS

Der unkomplizierte Einstieg mit fertigen Stimmen aus dem Microsoft-Katalog.

Online · Nein, Katalogstimme

gTTS

Schnelle Google-Voice über Google Translate Text-to-Speech mit Sprachcode.

Online · Nein, Sprachcode

Piper

Schnelle lokale Ausgabe mit einem vorhandenen oder selbst trainierten ONNX-Modell.

Lokal · CPU, optional CUDA

Chatterbox V2

Übernimmt Stimmcharakter und Sprechweise aus einer kurzen, sauberen Aufnahme.

Referenzstimme · GPU empfohlen

Piper lokal ergänzen

In derselben virtuellen Umgebung installieren und danach eine passende Stimme laden:

python -m pip install -e ".[desktop,piper]"
New-Item -ItemType Directory -Force ".\Stimmen"
python -m piper.download_voices --download-dir ".\Stimmen" de_DE-thorsten-medium

Piper: ONNX plus passende JSON, optionale Sprecher-ID und einstellbares Sprechtempo.

Eigene Referenzstimme mit Chatterbox

Wegen der Audio-/Torch-Abhängigkeiten wird eine eigene Python-3.11-Umgebung empfohlen:

py -3.11 -m venv .venv-chatterbox
.\.venv-chatterbox\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -e ".[desktop,voice-clone]"
python -m linguoai
  • 6–10 Sekunden, eine Person, wenig Hall, keine Musik oder Nebengeräusche.
  • Etwa 3,7 GB Modelldownload; CPU ist möglich, für längere Videos aber sehr langsam.
  • Die native Installation ist experimentell; Colab oder Linux ist bei Audio-Paketproblemen verlässlicher.
Stimme mit Verantwortung verwenden

Für Chatterbox ist die Bestätigung verpflichtend, dass du die Stimme verwenden darfst. Nutze deine eigene Aufnahme oder hole eine ausdrückliche Erlaubnis ein. Die Ausgabe enthält außerdem ein eingebettetes PerTh-Wasserzeichen.

Referenzstimmen enthalten biometrisch sensible Merkmale. Die Bestätigung in LinguoAI ersetzt keine Einwilligung; auch Piper-Engine und Stimmenmodell können getrennte Lizenzen besitzen.

Für wiederholbare Abläufe

Kommandozeile

Dieses Beispiel übersetzt lokal mit NLLB und verwendet ein Piper-Modell. Für Automatisierung stehen dieselben Einstellungen wie in der GUI zur Verfügung.

Eigene Ausgabe- und Modellpfade

PowerShell · Piper lokal 
python -m linguoai `
  --input "C:\Videos\quelle.mp4" `
  --output "C:\Videos\quelle.de.mp4" `
  --language de `
  --service nllb `
  --device cpu `
  --nllb-device cpu `
  --tts-engine piper `
  --tts-device cpu `
  --piper-model "C:\Stimmen\de_DE-thorsten-medium.onnx" `
  --piper-config "C:\Stimmen\de_DE-thorsten-medium.onnx.json"

Alle Optionen anzeigen: python -m linguoai --help

Rechenleistung sinnvoll verteilen

CPU und GPU sind keine Alles-oder-nichts-Entscheidung.

Whisper, NLLB und die lokale Stimme lassen sich getrennt platzieren. So kannst du klein anfangen und nur den Teil auf die GPU legen, der wirklich davon profitiert.

„Automatisch“ prüft CUDA und fällt sonst auf CPU zurück.

Wichtig: Die Auswahl „GPU“ installiert CUDA nicht automatisch.
  • NLLB & Chatterbox

    Benötigen eine passende CUDA-Ausgabe von PyTorch.

    PyTorch-Auswahl ↗
  • Faster-Whisper

    Benötigt zusätzlich CUDA-12-cuBLAS und cuDNN 9 im Systempfad.

  • Piper

    Nutzt ONNX Runtime: onnxruntime-gpu statt der CPU-Ausgabe installieren.

Optional schneller auf der CPU

Parakeet oder Whisper?

Parakeet · 25 Sprachen

NVIDIA Parakeet v3 erkennt 25 europäische Sprachen. Der optionale sherpa-onnx-Adapter arbeitet lokal auf der CPU mit standardmäßig vier Threads.

NVIDIA-Modellkarte ↗

Whisper · vielseitig

Faster-Whisper bleibt die Voreinstellung mit automatischer Spracherkennung, größerer Sprachauswahl und CPU- oder GPU-Verarbeitung.

Faster-Whisper ↗

Der primeline-Fine-Tune ist auf Deutsch spezialisiert. Wähle dafür das Deutsch-Profil mit einem passenden ONNX-Export; für mehrere europäische Sprachen das NVIDIA-Profil. Ein Geschwindigkeits- oder Qualitätsvorteil ist ohne Vergleich mit deinen Dateien nicht garantiert.

Parakeet einrichten

Das optionale Paket installieren und einen kompatiblen Modellordner bereitstellen. Ein Modell wird nicht automatisch heruntergeladen.

python -m pip install -e ".[parakeet]"
python -m linguoai --help

Den vollständigen sherpa-onnx-Modellordner mit Encoder, Decoder, Joiner und Token-Datei verwenden. Beim Deutsch-Export auch die externe Encoder-Datei behalten, falls sie zum Modell gehört.

In Desktop und Colab die Spracherkennung, das Profil und den Modellordner wählen. Die Quellsprache ausdrücklich angeben, damit die Übersetzung den richtigen Sprachcode erhält. Parakeet transkribiert; die gewählte Übersetzung und Stimme folgen danach.

Der vollständige Werkzeugkasten

Alle Funktionen im Detail.

Dateien und Aufträge
  • Ein einzelnes Video oder alle direkt enthaltenen Videos eines Ordners verarbeiten.
  • Eingaben: MP4, MKV, MOV, AVI, WEBM und M4V; Ausgaben: MP4, MKV oder MOV.
  • Automatischer Ausgabevorschlag, kollisionsfreie Namen und kontrolliertes Überschreiben.
  • Fortschritt pro Datei, aktueller Arbeitsschritt, Abbruch und technisches Protokoll.
  • Einzel- und Stapelverarbeitung: mehrere Videos hochladen oder MyDrive-Dateipfade eingeben, einen pro Zeile. Piper-Dateien und Referenzaufnahme per Upload oder MyDrive-Pfad.
Transkription mit Faster-Whisper
  • Modelle von tiny bis large-v3, zusätzlich eigene Modellwerte.
  • Quellsprache automatisch erkennen oder als Sprachcode festlegen.
  • CPU, NVIDIA-CUDA oder automatische Auswahl; int8, float16 und float32 konfigurierbar.
  • Überlappende Audioabschnitte, echte Zeit-Offsets und Bereinigung doppelter Segmente.
  • Chunklänge, Überlappung und Worker-Anzahl über erweiterte Optionen beziehungsweise CLI.
Übersetzung und Textschutz
  • NLLB-200 lokal, Google Translate ohne Schlüssel, DeepL-SDK oder Gemini.
  • Optionaler Fallback nur nach ausdrücklicher Auswahl – sonst wird nur ein Anbieter kontaktiert.
  • URLs, E-Mail-Adressen, Währungen, Einheiten und Prozentwerte werden beim Übersetzen geschützt.
  • Timeouts, begrenzte Wiederholungen und Cache für identische Textabschnitte.
  • Optional korrigiert Gemini das Whisper-Transkript, ohne Segment-IDs oder Zeiten zu ändern.
  • Eigene NLLB-kompatible Modelle, feste Revisionen, FLORES-Codes, Batch- und Tokenlimits.

Das voreingestellte NLLB-600M-Modell steht unter CC-BY-NC-4.0, ist ein Forschungsmodell und keine zertifizierte Produktionsübersetzung. Ergebnisse immer prüfen.

Timing, Ton und Export
  • Jeden Clip auf 48-kHz-Mono-PCM normalisieren und samplegenau positionieren.
  • Zu lange Sprache innerhalb einer konfigurierbaren Grenze beschleunigen.
  • Warnung bei starker Beschleunigung; kontrollierter Fehler statt unverständlicher Ausgabe.
  • Exakte Enddauer, übernommene Metadaten/Kapitel und möglichst unveränderter Videostream.
  • Atomare Ergebnisgruppe aus neuem Video, Original-SRT und Übersetzungs-SRT.
Wo deine Daten verarbeitet werden
  • NLLB · Piper · Chatterbox

    Nach dem Download in deiner gewählten Laufzeit. In Colab bedeutet das innerhalb der temporären Google-VM.

  • Google · DeepL · Gemini

    Erhalten Textabschnitte nur bei Auswahl oder als ausdrücklich aktivierter Fallback.

  • Edge TTS · gTTS

    Senden jeden zu vertonenden übersetzten Cue an den jeweiligen Online-Sprachdienst.

  • Geschützte Gradio-Weboberfläche mit zufälligem Passwort pro Sitzung.
  • Optionaler Modellcache und atomare Ergebniskopie in Google Drive.
  • Drive-Pfade bleiben innerhalb von MyDrive; Drive wird nicht als öffentlicher Downloadordner freigegeben.

Temporäre Ergebnisse werden erst veröffentlicht, wenn Video und beide Untertitel vollständig sind. Abbruch, begrenzte Wiederholungen, geschützte Zielpfade und redigierte API-Schlüssel vermeiden böse Überraschungen.

Was LinguoAI bewusst nicht verspricht

  • Synchrones Timing ist keine Lippenbewegungs-Synchronisation; das Bild wird nicht verändert.
  • Die neue Sprachspur ersetzt den Originalton vollständig. Musik, Atmosphäre und Geräusche werden derzeit nicht übernommen.
  • Keine Sprechererkennung und keine automatische Mehrsprecher-Zuweisung.
  • Transkript, Übersetzung, Aussprache und Stimmähnlichkeit vor Veröffentlichung immer prüfen.
  • Colab-GPU, Sitzungslänge und Abschluss großer Jobs sind nicht garantiert.

OPTIONAL

Eigene Adresse mit Cloudflare Tunnel.

Mit SHARE_PROVIDER = "gradio" erhältst du automatisch einen dynamischen Link. Google Drive ist optional.

Cloudflare optional

Nur für eine eigene feste Adresse: einen benannten Cloudflare Tunnel mit eigener Domain und dem Service http://127.0.0.1:7860 einrichten. Dies ist kein öffentlich bereitgestellter LinguoAI-Server.

Im Notebook SHARE_PROVIDER auf "cloudflare" setzen, CLOUDFLARE_TUNNEL_HOSTNAME mit dem eigenen Hostnamen füllen und CLOUDFLARE_TUNNEL_TOKEN als Colab Secret speichern. Token nie veröffentlichen.

Cloudflare: standardmäßig 95 MB pro Upload. Gradio: bis zu 5 GB pro Datei. Für große Videos Google Drive verwenden. Temporäre trycloudflare.com-Links werden wegen fehlender SSE-Unterstützung nicht verwendet.
