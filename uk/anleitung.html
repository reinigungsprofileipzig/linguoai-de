Windows і Linux

Встановити локально

Вам потрібні Python 3.10 або новіша версія, а також FFmpeg і ffprobe. Python 3.11 рекомендовано для Chatterbox. Потім відкрийте новий PowerShell.

Завантажити версію 2.2.1 ↓

Завантажте, повністю розпакуйте та дотримуйтеся локальних інструкцій.

PowerShell · Базове налаштування 
# FFmpeg einmalig installieren
winget install --id Gyan.FFmpeg --exact

# Im entpackten Projektordner ausführen; Pfad anpassen
cd "C:\Pfad\zu\LinguoAI-2.2.1"
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1

python -m pip install --upgrade pip
python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
python -m pip install -e ".[desktop]"
ffmpeg -version
ffprobe -version
python -m linguoai

У прикладі навмисно встановлюється версія CPU. Для NVIDIA спочатку виберіть відповідну команду Майстер встановлення PyTorch. Edge TTS і gTTS вже включені. Для Piper ви встановлюєте .[desktop,piper], для Chatterbox у власному середовищі .[desktop,voice-clone].

Ваше перше завдання в інтерфейсі
  1. Виберіть відео

    Натисніть «Файл…» під «Пуск». Пропонується цільовий шлях.

  2. Встановити мови

    вибрати мову перекладу; вихідна мова може бути розпізнана автоматично.

  3. Виберіть перекладач

    Для місцевих: NLLB. Для швидкого тесту: Google. DeepL/Gemini потребують свого ключа; окрема оптимізація Gemini.

  4. Визначити голос

    Негайно протестуйте Edge або gTTS; Ви встановлюєте Piper або Chatterbox у розділі «Додатково».

  5. Почніть обробку

    стежити за прогресом; у кінці відео та обидва файли SRT відкриваються безпосередньо.

Чотири способи отримати голосову доріжку

Порівняти голоси

«Власний голос» може означати різні речі. Це порівняння допоможе вам зробити правильний вибір.

Edge TTS

Простий спосіб почати роботу з готовими голосами з каталогу Microsoft.

Онлайн · Ні, голос каталогу

gTTS

Швидкий Google Voice через Google Translate Text-to-Speech з голосовим кодом.

Онлайн · Ні, код мови

Piper

Швидкий локальний вихід за допомогою існуючої або самонавченої моделі ONNX.

Місцевий · CPU, опціонально CUDA

Chatterbox V2

Переймає вокальний характер і манеру говорити з короткого, чистого запису.

Довідковий голос · Рекомендовано GPU

Додайте Piper локально

Встановіть у тому ж віртуальному середовищі, а потім завантажте відповідний голос:

python -m pip install -e ".[desktop,piper]"
New-Item -ItemType Directory -Force ".\Stimmen"
python -m piper.download_voices --download-dir ".\Stimmen" de_DE-thorsten-medium

Piper: ONNX плюс відповідний JSON, додатковий ідентифікатор динаміка та регульована швидкість розмови.

Власний контрольний голос із Chatterbox

Через залежності аудіо/факела рекомендується спеціальне середовище Python-3.11:

py -3.11 -m venv .venv-chatterbox
.\.venv-chatterbox\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -e ".[desktop,voice-clone]"
python -m linguoai
  • 6-10 секунд, одна людина, невелика реверберація, без музики чи фонового шуму.
  • Завантаження моделі приблизно 3,7 ГБ; CPU можливий, але дуже повільний для довших відео.
  • Рідна установка є експериментальною; Colab або Linux є більш надійними для вирішення проблем з аудіопакетами.
Використовуйте свій голос відповідально

Для Chatterbox підтвердження того, що ви можете використовувати голос, є обов’язковим. Використовуйте власний запис або отримайте чіткий дозвіл. Результат також містить вбудований водяний знак PerTh.

Довідкові голоси містять біометрично чутливі функції. Підтвердження в LinguoAI не замінює згоду; Механізм Piper і модель голосу також можуть мати окремі ліцензії.

Для повторюваних процесів

Командний рядок

Цей приклад локально перекладається на NLLB і використовує модель Piper. Для автоматизації доступні ті ж налаштування, що і в GUI.

Власний вихід і шляхи моделі

PowerShell · Piper локально 
python -m linguoai `
  --input "C:\Videos\quelle.mp4" `
  --output "C:\Videos\quelle.de.mp4" `
  --language de `
  --service nllb `
  --device cpu `
  --nllb-device cpu `
  --tts-engine piper `
  --tts-device cpu `
  --piper-model "C:\Stimmen\de_DE-thorsten-medium.onnx" `
  --piper-config "C:\Stimmen\de_DE-thorsten-medium.onnx.json"

Переглянути всі варіанти: python -m linguoai --help

Python-Wheel

Готовий пакет для існуючого середовища Python; FFmpeg все ще потрібен.

Навантаження Wheel ↓

python -m pip install ".\linguoai-2.2.1-py3-none-any.whl[desktop]"
python -m linguoai

Розумно розподіляйте обчислювальну потужність

CPU і GPU не є рішенням «все або нічого».

Whisper, NLLB і місцевий голос можна розмістити окремо. Тож ви можете почати з малого та встановити на GPU лише ту частину, яка справді виграє від цього.

«Автоматично» перевіряє CUDA і в іншому випадку повертається до CPU.

Важливо: вибір «GPU» не інсталює CUDA автоматично.
  • NLLB і Chatterbox

    Потрібне відповідне видання CUDA PyTorch.

    Вибір PyTorch ↗
  • Faster-Whisper

    Крім того, потрібні CUDA-12-cuBLAS і cuDNN 9 у системному шляху.

  • Piper

    Використовує ONNX Час виконання: onnxruntime-gpu встановити замість версії CPU.

Додатковий варіант для швидшого розпізнавання на CPU

Parakeet чи Whisper?

Parakeet · 25 мов

NVIDIA Parakeet v3 розпізнає 25 європейських мов. Додатковий адаптер sherpa-onnx працює локально на CPU, за замовчуванням у чотири потоки.

Картка моделі NVIDIA ↗

Whisper · універсальний

Faster-Whisper залишається типовим варіантом: автоматичне визначення мови, ширший вибір мов і обробка на CPU або GPU.

Faster-Whisper ↗

Модель primeline спеціалізується на німецькій мові. Для неї оберіть німецький профіль із відповідним ONNX-експортом; для кількох європейських мов — профіль NVIDIA. Перевага у швидкості чи якості не гарантується без порівняння на ваших файлах.

Налаштувати Parakeet

Встановіть додатковий пакет і підготуйте папку із сумісною моделлю. Моделі не завантажуються автоматично.

python -m pip install -e ".[parakeet]"
python -m linguoai --help

Використовуйте повну папку моделі sherpa-onnx з encoder, decoder, joiner і файлом токенів. Для німецького експорту також збережіть зовнішній файл encoder, якщо він є частиною моделі.

У застосунку для комп’ютера та Colab оберіть рушій розпізнавання мовлення, профіль і папку моделі. Явно вкажіть вихідну мову, щоб переклад отримав правильний код мови. Parakeet розпізнає мовлення; потім виконується переклад і використовується обраний голос.

Моделі й налаштування sherpa-onnx ↗ · Картка моделі primeline ↗

Повний інструментарій

Всі функції детально.

Картотеки та замовлення
  • Обробка окремого відео або всіх відео, які безпосередньо містяться в папці.
  • Входи: MP4, MKV, MOV, AVI, WEBM і M4V; Редакції: MP4, MKV або MOV.
  • Автоматична пропозиція виводу, імена без колізій і контрольоване перезапис.
  • Перебіг за файлом, поточний крок роботи, скасування та технічний журнал.
  • Одиночна й пакетна обробка: завантажте кілька відео або введіть шляхи до файлів MyDrive, по одному в рядку. Файли Piper і зразок голосу можна завантажити або вказати їхні шляхи в MyDrive.
Транскрипція з Faster-Whisper
  • Моделі tiny поки large-v3, додатково власні значення моделі.
  • Автоматично визначати вихідну мову або встановлювати як код мови.
  • CPU, NVIDIA-CUDA або автоматичний вибір; int8, float16 і float32, які можна налаштувати.
  • Аудіорозділи, що перекриваються, справжні часові зсуви та очищення дублікатів сегментів.
  • Довжина фрагментів, перекриття та номер робочого елемента за допомогою додаткових параметрів або CLI.
Переклад і захист тексту
  • NLLB-200 локальний, Google Translate без ключа, DeepL-SDK або Gemini.
  • Необов’язковий резервний варіант лише після явного вибору – інакше буде зв’язано лише з одним постачальником.
  • URL, адреси електронної пошти, валюти, одиниці та відсотки захищені під час перекладу.
  • Тайм-аути, обмежені повтори та кеш для ідентичних текстових розділів.
  • За бажанням Gemini виправляє розшифровку Whisper без зміни ідентифікаторів сегментів або часу.
  • Власні моделі, сумісні з NLLB, виправлені версії, коди FLORES, обмеження партій і маркерів.

Модель NLLB-600M за умовчанням відповідає CC-BY-NC-4.0, є дослідницькою моделлю, а не сертифікованим виробничим перекладом. Завжди перевіряйте результати.

Хронометраж, тон і експорт
  • Нормалізуйте кожен кліп до 48 кГц моно PCM і розташуйте його з точністю вибірки.
  • Прискорення надто довгого мовлення в межах встановленого ліміту.
  • Попередження при швидкому розгоні; контрольована помилка замість незрозумілого результату.
  • Точна кінцева тривалість, прийняті метадані/розділи та, якщо можливо, незмінний відеопотік.
  • Група результатів Atomic з нового відео, оригінального SRT і перекладу SRT.
Де обробляються ваші дані
  • NLLB · Piper · Chatterbox

    Після завантаження в обраний вами термін. У Colab це означає всередині тимчасової віртуальної машини Google.

  • Google · DeepL · Gemini

    Отримувати лише текстові розділи, якщо їх вибрано або як явно активований запасний варіант.

  • Edge TTS · gTTS

    Надсилайте кожну перекладену репліку на дубляж до відповідної мовної онлайн-служби.

  • Захищений веб-інтерфейс Gradio із довільним паролем на сеанс.
  • Додатковий кеш моделі та атомарна копія результату в Google Drive.
  • Шляхи приводу залишаються в межах MyDrive; Диск не є загальнодоступною папкою для завантажень.

Тимчасові результати не будуть опубліковані, доки відео та обидва субтитри не будуть завершені. Скасування, обмежені повторні спроби, захищені шляхи призначення та відредаговані ключі API дозволяють уникнути неприємних сюрпризів.

Чого LinguoAI свідомо не обіцяє

  • Синхронний час не є синхронізацією рухів губ; зображення не змінено.
  • Нова голосова доріжка повністю замінює оригінальний звук. Музика, атмосфера та звуки наразі не адаптуються.
  • Немає розпізнавання мовців і автоматичного призначення кількох мовців.
  • Перед публікацією завжди перевіряйте транскрипцію, переклад, вимову та схожість голосу.
  • Colab-GPU, тривалість сеансу та виконання великих завдань не гарантуються.

НЕОБОВ’ЯЗКОВО

Власна адреса через Cloudflare Tunnel.

За SHARE_PROVIDER = "gradio" динамічне посилання створюється автоматично. Google Drive необов’язковий.

Cloudflare за бажанням

Лише для власної постійної адреси: налаштуйте іменований Cloudflare Tunnel зі своїм доменом і сервісом http://127.0.0.1:7860. Це не загальнодоступний сервер LinguoAI.

У Notebook установіть SHARE_PROVIDER = "cloudflare", укажіть власний хост у CLOUDFLARE_TUNNEL_HOSTNAME і збережіть CLOUDFLARE_TUNNEL_TOKEN у Colab Secrets. Ніколи не публікуйте токен.

Cloudflare: за замовчуванням 95 MB на завантаження. Gradio: до 5 GB на файл. Для великих відео використовуйте Google Drive. Тимчасові посилання trycloudflare.com не використовуються через відсутність підтримки SSE.
