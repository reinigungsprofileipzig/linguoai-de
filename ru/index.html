Открыть интерфейс

Выберите видео, пункт назначения, переводчик и голос. Проверка системы сразу покажет вам, отсутствует ли пакет или модель.

PowerShell · Базовая настройка 
# FFmpeg einmalig installieren
winget install --id Gyan.FFmpeg --exact

# Im Projektordner ausführen
cd "C:\Pfad\zu\LinguoAI-2.2.1"
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1

python -m pip install --upgrade pip
python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
python -m pip install -e ".[desktop]"
ffmpeg -version
ffprobe -version
python -m linguoai

В примере намеренно установлена версия CPU. Для NVIDIA сначала выберите соответствующую команду в Мастер установки PyTorch. Edge TTS и gTTS уже включены. Для Piper вы устанавливаете .[desktop,piper], для Chatterbox в своей среде .[desktop,voice-clone].

gTTS входит в базовую комплектацию. Его можно установить индивидуально следующим образом:

Полное локальное задание

Этот пример локально преобразуется в NLLB и использует модель Piper. Для автоматизации доступны те же настройки, что и в GUI.

  • Одно видео или вся папка
  • Собственные пути вывода и модели
  • Явная ассоциация CPU/GPU
  • Тихий или подробный режим отладки
PowerShell · Piper локально 
python -m linguoai `
  --input "C:\Videos\quelle.mp4" `
  --output "C:\Videos\quelle.de.mp4" `
  --language de `
  --service nllb `
  --device cpu `
  --nllb-device cpu `
  --tts-engine piper `
  --tts-device cpu `
  --piper-model "C:\Stimmen\thorsten.onnx" `
  --piper-config "C:\Stimmen\thorsten.onnx.json"

Посмотреть все варианты: python -m linguoai --help

Распределяйте вычислительную мощность разумно

CPU и GPU не являются решением «все или ничего».

Whisper, NLLB и местный голос можно разместить отдельно. Таким образом, вы можете начать с малого и устанавливать на GPU только ту часть, которая действительно выиграет от этого.

WhisperCPU · int8
NLLBGPU · CUDA
PiperCPU
«Автоматически» проверяет CUDA и в противном случае возвращается к CPU.
Важно: выбор «GPU» не приводит к автоматической установке CUDA.
  • NLLB и Chatterbox

    Нужна соответствующая версия CUDA PyTorch.

    Выбор PyTorch ↗

    Дополнительно требуется CUDA-12-cuBLAS и cuDNN 9 в системном пути.

    Использует среду выполнения ONNX: onnxruntime-gpu установите вместо версии CPU.

01Файлы и заказы+
  • Обработка одного видео или всех видео, содержащихся непосредственно в папке.
  • Входы: MP4, MKV, MOV, AVI, WEBM и M4V; Редакции: MP4, MKV или MOV.
  • Автоматическое предложение вывода, имена без коллизий и контролируемая перезапись.
  • Прогресс по файлу, текущий этап работы, отмена и технический журнал.

Папки намеренно не просматриваются рекурсивно. В Colab на один заказ запускается одно видео.

02Транскрипция с помощью Faster-Whisper+
  • Модели tiny пока large-v3, а также собственные значения модели.
  • Автоматически определять исходный язык или устанавливать его в качестве кода языка.
  • CPU, NVIDIA-CUDA или автоматический выбор; int8, float16 и float32 настраиваются.
  • Перекрытие аудиофрагментов, смещение истинного времени и очистка повторяющихся сегментов.
  • Длины блоков, перекрытие и номер рабочего через дополнительные параметры или CLI.
03Перевод и защита текста+
  • NLLB-200 локальный, Google Translate без ключа, DeepL-SDK или Gemini.
  • Необязательный возврат только после явного выбора — в противном случае будет связываться только с одним поставщиком.
  • URL, адреса электронной почты, валюты, единицы измерения и проценты защищены во время перевода.
  • Таймауты, ограниченное количество повторов и кэш для одинаковых текстовых разделов.
  • При желании Gemini исправляет транскрипт Whisper без изменения идентификаторов сегментов или времени.
  • Собственные модели, совместимые с NLLB, фиксированные версии, коды FLORES, ограничения на партии и токены.

Модель NLLB-600M по умолчанию находится под CC-BY-NC-4.0 и представляет собой исследовательскую модель, а не сертифицированный производственный перевод. Всегда проверяйте результаты.

04Edge, gTTS, Piper и Chatterbox+
  • Edge: автоматический голос по умолчанию или собственный полный голосовой идентификатор Edge.
  • gTTS: Google Translate Преобразование текста в речь с автоматическим целевым языком или языковым кодом.
  • Piper: ONNX плюс соответствующий JSON, дополнительный идентификатор динамика и регулируемая скорость речи.
  • Chatterbox V2: проверка ссылок, распечатка, надежность конфигурации конфигурации, подтверждение прав и водяной знак.
  • Запустите локальный движок на CPU, CUDA или автоматически с резервным вариантом CPU.
  • Модели загружаются только для выбранного движка, а затем снова выпускаются.

gTTS и Edge — это онлайн-сервисы, а не голосовые клоны. LinguoAI загружает модели Piper, но не обучает их. Для каждого заказа используется один голос. Chatterbox отклоняет ссылки ниже 0,5 или выше 60 секунд и практически рекомендует 6-10 секунд.

05Тайминг, тон и экспорт+
  • Нормализуйте каждый клип до моно PCM с частотой 48 кГц и расположите его с точностью до сэмпла.
  • Ускорьте речь, которая слишком длинна в пределах настраиваемого предела.
  • Предупреждение при быстром ускорении; контролируемая ошибка вместо непонятного вывода.
  • Точная продолжительность окончания, принятые метаданные/главы и, если возможно, неизмененный видеопоток.
  • Атомная группа результатов из нового видео, оригинального SRT и перевода SRT.
06Интерфейс рабочего стола и CLI+
  • Три вкладки GUI: «Главная», «Дополнительно» и «Журнал»; плюс светлый и темный режим.
  • Динамические поля, проверка системы, маркировка локально/онлайн и уведомление о защите данных.
  • Открыть полученное видео или папку вывода напрямую; Скопируйте или очистите журнал.
  • Клавиатура: Strg+O, Strg+Enter и Esc.
  • CLI для заданий файлов/папок со всеми параметрами устройства, модели, времени ожидания и отладки.
07Colab, Проезд и безопасные пути+
  • Защищенный веб-интерфейс Gradio со случайным паролем для каждого сеанса.
  • Одиночная и пакетная обработка: загрузите несколько видео или введите пути к файлам MyDrive, по одному в строке. Файлы Piper и эталонную запись можно загрузить или указать их пути в MyDrive.
  • Дополнительный кеш модели и атомарное копирование результатов в Google Drive.
  • Готовое видео и оба файла SRT для каждого задания; 5 GB на загрузку через Gradio или по умолчанию 95 MB через необязательный Cloudflare Tunnel.
  • Пути привода остаются в пределах MyDrive; Диск не является общедоступной папкой для скачивания.
08Чего LinguoAI намеренно не обещает+
  • Синхронный расчет времени — это не синхронизация движений губ; изображение не изменено.
  • Новая голосовая дорожка полностью заменяет исходное звучание. Музыка, атмосфера и звуки на данный момент не принимаются.
  • Нет распознавания говорящего и автоматического назначения нескольких динамиков.
  • Всегда проверяйте расшифровку, перевод, произношение и сходство голоса перед публикацией.
  • Colab-GPU, продолжительность сеанса и выполнение больших заданий не гарантируются.

Все еще не уверены?

Часто задаваемые вопросы, понятные ответы.

Для первой попытки достаточно короткого видео, Edge TTS и стандартных настроек.

Могу ли я использовать LinguoAI без установки?+

Да. Откройте подготовленный Notebook с помощью кнопки «Открыть в Colab» и выберите «Среда выполнения → Выполнить все». Notebook автоматически загружает ZIP-архив исходного кода через защищенный адрес загрузки на этом веб-сайте. Все, что вам нужно, это учетная запись Google; ссылка Gradio работает до тех пор, пока активен сеанс Colab.

Может ли LinguoAI использовать мой собственный голос?+

Да. Chatterbox использует авторизованный голос из короткой контрольной записи. Альтернативно вы можете использовать Piper для загрузки собственной уже обученной модели ONNX. Edge TTS предлагает только готовые детали из каталога; gTTS использует голосовые коды Google, но не собственную голосовую копию.

Программа работает полностью локально?+

При использовании Faster-Whisper, NLLB и Piper или Chatterbox обработка запускается в выбранной среде выполнения после начальной загрузки модели. На рабочем столе это ваш компьютер; в Colab это временная виртуальная машина Google. Edge TTS, gTTS, Google Translate, DeepL и Gemini — это онлайн-сервисы.

Нужна ли мне мощная видеокарта?+

Нет. Whisper, NLLB и Piper работают на CPU. Chatterbox также работает, но значительно медленнее. NVIDIA-GPU полезен для более длительных проектов.

Что я получу в итоге?+

Недавно озвученное видео и два файла SRT: один с распознанным оригинальным текстом, другой с переводом. Само исходное видео остается неизменным.

Могу ли я загружать файлы напрямую с Google Drive?+

Да, в интерфейсе Colab. Вы можете указать безопасный относительный путь в MyDrive и записать результаты обратно в папку на Диске.

Какие языки поддерживает ваш собственный эталонный голос?+

Chatterbox Multilingual V2 поддерживает 23 основных языка, включая немецкий, английский, французский, испанский, итальянский, португальский, польский, турецкий, японский, корейский и китайский. Piper зависит от языка выбранной модели. gTTS поддерживает многие языковые коды Google Translate, но не поддерживает речевые голоса.

Короткое тестовое видео — лучшее начало.
