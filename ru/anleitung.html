Однократная настройка

Установка на компьютер с Windows

Вам нужен компьютер с Windows, интернетом и несколькими гигабайтами свободного места. Готового установщика пока нет. Следующие шаги помогут установить программу. Уметь программировать не нужно.

  1. 01

    Установите две вспомогательные программы

    Откройте меню «Пуск» Windows, введите PowerShell и откройте программу. Копируйте следующие строки по одной и после каждой нажимайте Enter. Ждите завершения установки, прежде чем вводить следующую строку.

    PowerShell
    winget install --id Python.Python.3.11 --exact --source winget
    winget install --id Gyan.FFmpeg --exact --source winget

    Python запускает LinguoAI. FFmpeg читает и записывает видео. Если Windows запросит подтверждение, убедитесь, что запрос относится к этой установке.

    Готово? Обе установки сообщают об успехе или о том, что программа уже установлена. Теперь закройте PowerShell.

  2. 02

    Скачайте и распакуйте LinguoAI

    Скачайте ZIP-файл. В папке загрузок нажмите на него правой кнопкой мыши и выберите «Извлечь всё». Затем откройте распакованную папку.

    Скачать LinguoAI 2.2.1 ↓

    Вы в нужной папке, если видите файл pyproject.toml и папку linguoai .

  3. 03

    Откройте нужную папку

    В открытой папке нажмите адресную строку вверху. Введите powershell и нажмите Enter. Откроется новое окно. Скопируйте в него эти три команды проверки по одной:

    PowerShell
    py -3.11 --version
    ffmpeg -version
    ffprobe -version

    Вы увидите Python 3.11 и ещё два сообщения с номерами версий. Если появится «не найдено», прежде чем продолжить, воспользуйтесь помощью ниже.

  4. 04

    Настройте LinguoAI

    Оставайтесь в этом окне. Копируйте строки по одной и нажимайте Enter. После каждой строки ждите, пока снова можно будет вводить текст. В первый раз загрузятся большие файлы.

    PowerShell
    py -3.11 -m venv .venv
    .\.venv\Scripts\python.exe -m pip install --upgrade pip
    .\.venv\Scripts\python.exe -m pip install torch --index-url https://download.pytorch.org/whl/cpu
    .\.venv\Scripts\python.exe -m pip install -e ".[desktop]"

    Всё завершилось без ошибок? Настройка готова. Она нужна только один раз.

  5. 05

    Откройте программу

    Скопируйте эту строку в то же окно:

    PowerShell
    .\.venv\Scripts\python.exe -m linguoai

    Откроется окно LinguoAI. Не закрывайте PowerShell, пока пользуетесь LinguoAI.

Попробуйте сейчас

Ваше первое переведённое видео

Для начала возьмите короткое видео с чёткой речью, например на 30 секунд.

  1. На вкладке „Start“ нажмите „Datei …“ и выберите видео.
  2. Выберите нужный язык в поле „Zielsprache“ . Исходный язык можно определить автоматически.
  3. Для первого теста выберите «Google Translate · online» и «Edge TTS · online».
  4. Откройте «Erweitert» → «Leistung». В поле «Hardware für Spracherkennung» выберите «Nur CPU». Затем вернитесь в «Start». Остальные настройки можно оставить как есть.
  5. Нажмите „Verarbeitung starten“ . При первом запуске LinguoAI также загрузит модель распознавания речи. Это может занять время.
  6. Когда появится „FERTIG“ нажмите „Video öffnen“ . Нажмите „Ordner öffnen“ — откроется папка с видео и обоими файлами субтитров.
Полезно знать

В этом простом тесте Google и Microsoft получают текст для перевода и озвучки. Новый голос заменит весь исходный звук, включая музыку. Исходный файл останется без изменений.

Если что-то не получается

Как открыть LinguoAI в следующий раз?

Снова откройте распакованную папку LinguoAI. В адресной строке вверху введите powershell. Выполните только команду из шага 5. Повторять установку не нужно.

«winget» не найден

Установите или обновите «Установщик приложений» от Microsoft в Microsoft Store. Затем снова откройте PowerShell и повторите шаг 1.

Открыть инструкцию Microsoft ↗
Python или FFmpeg не найдены

Закройте PowerShell и откройте снова, как в шаге 3. Если это не помогло, перезагрузите компьютер и проверьте три строки ещё раз. Для этой инструкции нужен установленный Python 3.11.

Команда сообщает об ошибке

Пока не выполняйте следующую строку. Сначала проверьте, что вы находитесь в распакованной папке с файлом pyproject.toml и что вы скопировали всю строку. Сохраните точный текст ошибки на случай, если понадобится помощь.

Обработка идёт долго или не завершается

При первом запуске загружаются модели. Оставьте окно открытым и проверьте, продолжается ли обработка. Если LinguoAI сообщает об ошибке, прочитайте сообщение в журнале. Затем попробуйте более короткое видео.

Четыре способа получить голосовую дорожку

Сравнить голоса

«Собственный голос» может означать разное. Это сравнение поможет вам сделать правильный выбор.

Edge TTS

Простой способ начать работу с готовыми голосами из каталога Microsoft.

Онлайн · Нет, голос каталога

gTTS

Быстрый Google Voice через Google Translate преобразование текста в речь с голосовым кодом.

Онлайн · Нет, код языка

Piper

Быстрый локальный вывод с помощью существующей или самообучающейся модели ONNX.

Местный · CPU, опционально CUDA

Chatterbox V2

Перенимает вокальный характер и манеру речи из короткой чистой записи.

Эталонный голос · Рекомендуется GPU

Добавьте Piper локально.

Установите в ту же виртуальную среду, а затем загрузите подходящий голос:

.\.venv\Scripts\python.exe -m pip install -e ".[desktop,piper]"
New-Item -ItemType Directory -Force ".\Stimmen"
.\.venv\Scripts\python.exe -m piper.download_voices --download-dir ".\Stimmen" de_DE-thorsten-medium

Piper: ONNX плюс соответствующий JSON, дополнительный идентификатор динамика и регулируемая скорость речи.

Собственный эталонный голос с Chatterbox

Из-за зависимости аудио/фонарика рекомендуется использовать выделенную среду Python-3.11:

py -3.11 -m venv .venv-chatterbox
.\.venv-chatterbox\Scripts\python.exe -m pip install --upgrade pip
.\.venv-chatterbox\Scripts\python.exe -m pip install -e ".[desktop,voice-clone]"
.\.venv-chatterbox\Scripts\python.exe -m linguoai
  • 6–10 секунд, один человек, небольшая реверберация, никакой музыки и фонового шума.
  • Загрузка модели примерно 3,7 ГБ; CPU возможен, но очень медленный для более длинных видео.
  • Собственная установка является экспериментальной; Colab или Linux более надежны при проблемах с аудиопакетами.
Используйте свой голос ответственно

Для Chatterbox подтверждение возможности использования голоса является обязательным. Используйте свою собственную запись или получите явное разрешение. Вывод также содержит встроенный водяной знак PerTh.

Эталонные голоса содержат биометрически чувствительные функции. Подтверждение в LinguoAI не заменяет согласие; Движок Piper и голосовая модель также могут иметь отдельные лицензии.

Для повторяемых процессов

Командная строка

Этот пример локально преобразуется в NLLB и использует модель Piper. Для автоматизации доступны те же настройки, что и в GUI.

Собственные пути вывода и модели

PowerShell · Piper локально 
.\.venv\Scripts\python.exe -m linguoai `
  --input "C:\Videos\quelle.mp4" `
  --output "C:\Videos\quelle.de.mp4" `
  --language de `
  --service nllb `
  --device cpu `
  --nllb-device cpu `
  --tts-engine piper `
  --tts-device cpu `
  --piper-model "C:\Stimmen\de_DE-thorsten-medium.onnx" `
  --piper-config "C:\Stimmen\de_DE-thorsten-medium.onnx.json"

Посмотреть все варианты: .\.venv\Scripts\python.exe -m linguoai --help

Python-Wheel

Готовый пакет для существующей среды Python; FFmpeg по-прежнему требуется.

Загрузить Wheel ↓

python -m pip install ".\linguoai-2.2.1-py3-none-any.whl[desktop]"

Распределяйте вычислительную мощность разумно

CPU и GPU не являются решением «все или ничего».

Whisper, NLLB и местный голос можно разместить отдельно. Таким образом, вы можете начать с малого и устанавливать на GPU только ту часть, которая действительно выиграет от этого.

«Автоматически» проверяет CUDA и в противном случае возвращается к CPU.

Важно: выбор «GPU» не приводит к автоматической установке CUDA.
  • NLLB и Chatterbox

    Нужна соответствующая версия CUDA PyTorch.

    Выбор PyTorch ↗
  • Faster-Whisper

    Дополнительно требуется CUDA-12-cuBLAS и cuDNN 9 в системном пути.

  • Piper

    Использует среду выполнения ONNX: onnxruntime-gpu установите вместо версии CPU.

Дополнительный вариант для более быстрого распознавания на CPU

Parakeet или Whisper?

Parakeet · 25 языков

NVIDIA Parakeet v3 распознаёт 25 европейских языков. Дополнительный адаптер sherpa-onnx работает локально на CPU, по умолчанию в четыре потока.

Карточка модели NVIDIA ↗

Whisper · универсальный

Faster-Whisper остаётся вариантом по умолчанию: автоматическое определение языка, более широкий выбор языков и обработка на CPU или GPU.

Faster-Whisper ↗

Модель primeline специализируется на немецком языке. Для неё выберите немецкий профиль с подходящим ONNX-экспортом; для нескольких европейских языков — профиль NVIDIA. Преимущество в скорости или качестве не гарантировано без сравнения на ваших файлах.

Настроить Parakeet

Установите дополнительный пакет и подготовьте папку с совместимой моделью. Модели не скачиваются автоматически.

.\.venv\Scripts\python.exe -m pip install -e ".[parakeet]"
.\.venv\Scripts\python.exe -m linguoai --help

Используйте полную папку модели sherpa-onnx с encoder, decoder, joiner и файлом токенов. Для немецкого экспорта также сохраните внешний файл encoder, если он входит в модель.

В приложении для компьютера и Colab выберите движок распознавания речи, профиль и папку модели. Явно укажите исходный язык, чтобы перевод получил правильный код языка. Parakeet распознаёт речь; затем выполняется перевод и используется выбранный голос.

Полный набор инструментов

Все функции подробно.

Файлы и заказы
  • Обработка одного видео или всех видео, содержащихся непосредственно в папке.
  • Входы: MP4, MKV, MOV, AVI, WEBM и M4V; Редакции: MP4, MKV или MOV.
  • Автоматическое предложение вывода, имена без коллизий и контролируемая перезапись.
  • Прогресс по файлу, текущий этап работы, отмена и технический журнал.
  • Одиночная и пакетная обработка: загрузите несколько видео или введите пути к файлам MyDrive, по одному в строке. Файлы Piper и эталонную запись можно загрузить или указать их пути в MyDrive.
Транскрипция с помощью Faster-Whisper
  • Модели tiny пока large-v3, а также собственные значения модели.
  • Автоматически определять исходный язык или устанавливать его в качестве кода языка.
  • CPU, NVIDIA-CUDA или автоматический выбор; int8, float16 и float32 настраиваются.
  • Перекрытие аудиофрагментов, смещение истинного времени и очистка повторяющихся сегментов.
  • Длины блоков, перекрытие и номер рабочего через дополнительные параметры или CLI.
Перевод и защита текста
  • NLLB-200 локальный, Google Translate без ключа, DeepL-SDK или Gemini.
  • Необязательный возврат только после явного выбора — в противном случае будет связываться только с одним поставщиком.
  • URL, адреса электронной почты, валюты, единицы измерения и проценты защищены во время перевода.
  • Таймауты, ограниченное количество повторов и кэш для одинаковых текстовых разделов.
  • При желании Gemini исправляет транскрипт Whisper без изменения идентификаторов сегментов или времени.
  • Собственные модели, совместимые с NLLB, фиксированные версии, коды FLORES, ограничения на партии и токены.

Модель NLLB-600M по умолчанию находится под CC-BY-NC-4.0 и представляет собой исследовательскую модель, а не сертифицированный производственный перевод. Всегда проверяйте результаты.

Тайминг, тон и экспорт
  • Нормализуйте каждый клип до моно PCM с частотой 48 кГц и расположите его с точностью до сэмпла.
  • Ускорьте речь, которая слишком длинна в пределах настраиваемого предела.
  • Предупреждение при быстром ускорении; контролируемая ошибка вместо непонятного вывода.
  • Точная продолжительность окончания, принятые метаданные/главы и, если возможно, неизмененный видеопоток.
  • Атомная группа результатов из нового видео, оригинального SRT и перевода SRT.
Где обрабатываются ваши данные
  • NLLB · Piper · Chatterbox

    После загрузки в выбранный вами срок. В Colab это означает внутри временной виртуальной машины Google.

  • Google · DeepL · Gemini

    Получать текстовые разделы только при выборе или в качестве явно активированного резервного варианта.

  • Edge TTS · gTTS

    Отправьте каждую переведенную реплику для дублирования в соответствующий языковой онлайн-сервис.

  • Защищенный веб-интерфейс Gradio со случайным паролем для каждого сеанса.
  • Дополнительный кеш модели и атомарное копирование результатов в Google Drive.
  • Пути привода остаются в пределах MyDrive; Диск не является общедоступной папкой для скачивания.

Временные результаты не будут опубликованы до тех пор, пока не будут готовы видео и оба субтитра. Прерывание, ограниченное количество повторных попыток, защищенные пути назначения и отредактированные ключи API позволяют избежать неприятных сюрпризов.

Чего LinguoAI намеренно не обещает

  • Синхронный расчет времени — это не синхронизация движений губ; изображение не изменено.
  • Новая голосовая дорожка полностью заменяет исходное звучание. Музыка, атмосфера и звуки на данный момент не принимаются.
  • Нет распознавания говорящего и автоматического назначения нескольких динамиков.
  • Всегда проверяйте расшифровку, перевод, произношение и сходство голоса перед публикацией.
  • Colab-GPU, продолжительность сеанса и выполнение больших заданий не гарантируются.

Cloudflare по желанию

Только для собственного постоянного адреса: настройте именованный Cloudflare Tunnel со своим доменом и сервисом http://127.0.0.1:7860. Это не общедоступный сервер LinguoAI.

В Notebook установите SHARE_PROVIDER = "cloudflare", укажите свой хост в CLOUDFLARE_TUNNEL_HOSTNAME и сохраните CLOUDFLARE_TUNNEL_TOKEN в Colab Secrets. Никогда не публикуйте токен.

Cloudflare: по умолчанию 95 MB на загрузку. Gradio: до 5 GB на файл. Для больших видео используйте Google Drive. Временные ссылки trycloudflare.com не используются из-за отсутствия поддержки SSE.
