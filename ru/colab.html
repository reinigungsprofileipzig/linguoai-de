Без постоянной установки

Запустите LinguoAI в Google Colab.

Сначала скачайте готовый Notebook с linguoai.de. Затем откройте Google Colab и загрузите туда файл Notebook. ZIP-архив проекта автоматически скачивается с linguoai.de.

1. Загрузите Notebook ↓ 2. Откройте Google Colab. ↗

Загруженный файл называется LinguoAI_Colab.ipynb. Оставьте все как есть и выберите именно этот файл при загрузке в Colab.

Это то, что тебе нужно
  • учетная запись Google
  • короткое тестовое видео
  • активное подключение к Интернету

GPU в Colab необязателен. Для динамической ссылки Gradio не нужны аккаунт Cloudflare, собственный домен или токен туннеля.

Шаг за шагом

Вот как вы открываете Notebook.

  1. 01
    Скачать Notebook

    Нажмите «Загрузить Notebook» выше. Обычно файл попадает в папку «Загрузки».

  2. 02
    Открыть Google Colab

    Войдите в свою учетную запись Google и выберите «Загрузить» в главном окне.

  3. 03
    Загрузить файл

    Выберите файл LinguoAI_Colab.ipynb в папке загрузок и откройте его.

  4. 04
    Запустите Notebook

    В меню Colab выберите «Среда выполнения → Выполнить все». Одна ячейка кода с самопроверкой устанавливает LinguoAI и запускает интерфейс.

  5. 05
    Открыть веб-интерфейс Gradio

    Откройте созданную ссылку Gradio и войдите с показанными учётными данными. Загрузите одно или несколько видео либо введите пути к файлам Google Drive, по одному в строке.

ПЕРВЫЙ ТЕСТ

Вы можете оставить эти настройки.

PROJECT_SOURCE = "download_zip" автоматически скачивает LinguoAI с linguoai.de. При LOCAL_TTS_EXTRA = "none" Edge TTS и gTTS работают без большого дополнительного пакета голосов.

При SHARE_PROVIDER = "gradio" динамическая ссылка создаётся автоматически. Google Drive необязателен.

ВАЖНО

Сеансы Colab являются временными.

Скачайте готовые видео и оба файла SRT для каждого задания или сохраните их в Google Drive. Файлы в /content и ссылка Gradio исчезают после завершения сеанса.

НЕОБЯЗАТЕЛЬНО

Собственный адрес через Cloudflare Tunnel.

Только для собственного постоянного адреса: настройте именованный Cloudflare Tunnel со своим доменом и сервисом http://127.0.0.1:7860. Это не общедоступный сервер LinguoAI.

В Notebook установите SHARE_PROVIDER = "cloudflare", укажите свой хост в CLOUDFLARE_TUNNEL_HOSTNAME и сохраните CLOUDFLARE_TUNNEL_TOKEN в Colab Secrets. Никогда не публикуйте токен.

Cloudflare: по умолчанию 95 MB на загрузку. Gradio: до 5 GB на файл. Для больших видео используйте Google Drive. Временные ссылки trycloudflare.com не используются из-за отсутствия поддержки SSE.
