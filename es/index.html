Una herramienta, un proceso claro

Tú cuidas el idioma. LinguoAI se encarga del resto.

No hay magia oscura con un solo clic: todos los componentes importantes siguen siendo seleccionables, desde la transcripción hasta el traductor, pasando por la voz y el dispositivo utilizado.

Qué puede hacer el LinguoAI

Todo para la nueva versión de idioma.

La interfaz de escritorio, la versión CLI y Colab utilizan el mismo procesamiento robusto en segundo plano.

01

Reconocer el lenguaje con precisión

Faster-Whisper procesa la pista de audio en secciones superpuestas y conserva marcas de tiempo real. Usted mismo configura el modelo Whisper, CPU/GPU y el formato de cálculo.

  • Faster-Whisper
  • Reconocimiento de voz automático o fijo
  • Archivo y carpeta
02

Traducir apropiadamente

Elija Google, DeepL, Gemini o el NLLB-200 local. Solo se utilizará un segundo servicio si lo activa explícitamente como alternativa.

  • NLLB localmente en CPU o CUDA
  • Modelos propios NLLB compatibles
  • Optimización de texto opcional Gemini
03

Elige la voz adecuada

Voz online, modelo local ONNX o una grabación de referencia autorizada: Edge, gTTS, Piper y Chatterbox se pueden seleccionar libremente por pedido.

Comparar voces →
04

Mantente en el tiempo

Cada clip de voz se normaliza, se adapta a su ventana de tiempo y se clasifica con precisión de muestra. Las oraciones posteriores no se mueven simplemente.

  • PCM monocromático de 48 kHz
  • Ajuste de tempo limitado
  • Final exacto de los medios
05

Subtítulos incluidos

De cada vídeo terminado se crea un archivo SRT con el texto original y un segundo con la traducción. Esto significa que el resultado se puede utilizar de forma flexible.

  • Vídeo
  • Originales SRT.
  • Traducido SRT
06

Trabajar de forma segura y comprensible

Los resultados temporales no se publicarán hasta que el vídeo y ambos subtítulos estén completos. La cancelación, los reintentos limitados, las rutas de destino protegidas y las claves API redactadas evitan sorpresas desagradables.

  • Cancelar
  • Revertir
  • Tiempos de espera
  • No hay claves en los registros

Dónde se procesan tus datos

“Local” y “en línea” permanecen claramente separados.

LOCALESNLLB · Piper · Chatterbox

Después de descargar en el término elegido. En Colab eso significa dentro de la máquina virtual temporal de Google.

EN LÍNEAGoogle · DeepL · Gemini

Reciba solo secciones de texto cuando estén seleccionadas o como un respaldo activado explícitamente.

EN LÍNEAEdge TTS · gTTS

Envíe cada pista traducida para doblarla al servicio de idioma en línea respectivo.

Las voces de referencia contienen características biométricamente sensibles. La confirmación en LinguoAI no reemplaza el consentimiento; El motor Piper y el modelo de voz también pueden tener licencias independientes.

Abrir interfaz

Elige vídeo, destino, traductor y voz. La verificación del sistema le muestra directamente si aún falta un paquete o modelo.

PowerShell · Configuración básica 
# FFmpeg einmalig installieren
winget install --id Gyan.FFmpeg --exact

# Im Projektordner ausführen
cd "C:\Pfad\zu\LinguoAI-2.2.1"
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1

python -m pip install --upgrade pip
python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
python -m pip install -e ".[desktop]"
ffmpeg -version
ffprobe -version
python -m linguoai

El ejemplo configura deliberadamente la versión CPU. Para NVIDIA, primero seleccione el comando apropiado en Asistente de instalación PyTorch. Edge TTS y gTTS ya están incluidos. Para Piper usted instala .[desktop,piper], para Chatterbox en su propio entorno .[desktop,voice-clone].

gTTS / Usar Google Voice +

gTTS está incluido en el paquete básico. Se puede instalar individualmente así:

python -m pip install gTTS

La caja de herramientas completa

Todas las funciones en detalle.

No es necesario conocer todas las configuraciones para comenzar. Si necesita más control más adelante, encontrará todo el alcance aquí, sin promesas ocultas.

01Archivos y pedidos+
  • Procese un solo video o todos los videos contenidos directamente en una carpeta.
  • Entradas: MP4, MKV, MOV, AVI, WEBM y M4V; Ediciones: MP4, MKV o MOV.
  • Sugerencia de salida automática, nombres sin colisiones y sobrescritura controlada.
  • Avance por expediente, paso de trabajo actual, cancelación y registro técnico.

Las carpetas no se buscan deliberadamente de forma recursiva. En Colab se reproduce un vídeo por pedido.

02Transcripción con Faster-Whisper+
  • Modelos de tiny hasta large-v3, además valores propios del modelo.
  • Detecta automáticamente el idioma de origen o lo establece como código de idioma.
  • CPU, NVIDIA-CUDA o selección automática; int8, float16 y float32 configurables.
  • Secciones de audio superpuestas, compensaciones en tiempo real y limpieza de segmentos duplicados.
  • Longitudes de fragmentos, superposición y número de trabajadores a través de opciones avanzadas o CLI.
03Traducción y protección de textos+
  • NLLB-200 local, Google Translate sin llave, DeepL-SDK o Gemini.
  • Reserva opcional solo después de una selección explícita; de lo contrario, solo se contactará a un proveedor.
  • URL, direcciones de correo electrónico, monedas, unidades y porcentajes están protegidos durante la traducción.
  • Tiempos de espera, repeticiones limitadas y caché para secciones de texto idénticas.
  • Opcionalmente, Gemini corrige la transcripción Whisper sin cambiar los ID de segmento ni los tiempos.
  • Modelos propios compatibles con NLLB, revisiones fijas, códigos FLORES, límites de lotes y tokens.

El modelo predeterminado NLLB-600M está bajo CC-BY-NC-4.0, es un modelo de investigación y no una traducción de producción certificada. Comprueba siempre los resultados.

04Edge, gTTS, Piper y Chatterbox+
  • Edge: voz predeterminada automática o ID de voz propia y completa Edge.
  • gTTS: Google Translate Texto a voz con idioma de destino automático o código de idioma.
  • Piper: ONNX más JSON coincidente, ID de altavoz opcional y velocidad de conversación ajustable.
  • Chatterbox V2: Comprobación de referencias, impresión, solidez CFG, confirmación de derechos y marca de agua.
  • Ejecute el motor local en CPU, CUDA o automáticamente con el respaldo CPU.
  • Los modelos solo se cargan para el motor seleccionado y luego se lanzan nuevamente.

gTTS y Edge son servicios en línea y no clones de voz. LinguoAI carga modelos Piper pero no los entrena. Se utiliza un voto por pedido. Chatterbox rechaza referencias inferiores a 0,5 o superiores a 60 segundos y prácticamente recomienda 6-10 segundos.

05Sincronización, tono y exportación.+
  • Normalice cada clip a PCM mono de 48 kHz y colóquelo con precisión de muestra.
  • Acelere el habla demasiado larga dentro de un límite configurable.
  • Advertencia al acelerar rápidamente; error controlado en lugar de resultados incomprensibles.
  • Duración exacta del final, metadatos/capítulos adoptados y, si es posible, transmisión de video sin cambios.
  • Grupo de resultados atómicos del nuevo vídeo, SRT original y traducción SRT.
06Interfaz de escritorio y CLI+
  • Tres pestañas GUI: Inicio, Avanzado y Registro; además del modo claro y oscuro.
  • Campos dinámicos, verificación del sistema, etiquetado local/online y aviso de protección de datos.
  • Abra el vídeo de resultados o la carpeta de salida directamente; Copiar o vaciar el registro.
  • Teclado: Strg+O, Strg+Enter y Esc.
  • CLI para trabajos de archivos/carpetas con todas las opciones de dispositivo, modelo, tiempo de espera y depuración.
07Colab, Conducción y caminos seguros+
  • Interfaz web Gradio protegida con contraseña aleatoria por sesión.
  • Procesamiento individual y por lotes: sube varios vídeos o introduce rutas de archivos de MyDrive, una por línea. Sube los archivos de Piper y la grabación de referencia o indica sus rutas en MyDrive.
  • Caché de modelo opcional y copia de resultados atómicos en Google Drive.
  • Vídeo resultante y ambos archivos SRT por tarea; 5 GB por carga con Gradio o 95 MB de forma predeterminada mediante el Cloudflare Tunnel opcional.
  • Los caminos de acceso permanecen dentro de MyDrive; Drive no se comparte como una carpeta de descarga pública.
08Lo que el LinguoAI no promete deliberadamente+
  • La sincronización sincrónica no es sincronización del movimiento de los labios; la imagen no se cambia.
  • La nueva pista de voz reemplaza completamente el sonido original. Actualmente no se adoptan música, atmósfera ni sonidos.
  • Sin reconocimiento de locutor ni asignación automática de múltiples locutores.
  • Siempre verifique la transcripción, la traducción, la pronunciación y la similitud de voz antes de publicar.
  • Colab-GPU, la duración de la sesión y la finalización de trabajos grandes no están garantizados.

¿Aún no estás seguro?

Preguntas frecuentes, claramente respondidas.

Para el primer intento, basta con un vídeo corto, Edge TTS y la configuración estándar.

¿Puedo usar LinguoAI sin instalación?+

Sí. Abra el Notebook preparado usando el botón "Abrir en Colab" y seleccione "Tiempo de ejecución → Ejecutar todo". El Notebook descarga automáticamente el código fuente ZIP a través de la dirección de descarga segura en este sitio web. Todo lo que necesitas es una cuenta de Google; el enlace Gradio funciona mientras la sesión Colab esté activa.

¿Puedo LinguoAI usar mi propia voz?+

Sí. Chatterbox adopta una voz autorizada a partir de una breve grabación de referencia. Alternativamente, puede usar Piper para cargar su propio modelo ONNX que ya haya sido entrenado. Edge TTS solo ofrece piezas terminadas del catálogo; gTTS utiliza códigos de voz de Google, pero no su propia copia de voz.

¿El programa se ejecuta completamente localmente?+

Con Faster-Whisper, NLLB y Piper o Chatterbox, el procesamiento se ejecuta en el tiempo de ejecución seleccionado después de las descargas iniciales del modelo. En el escritorio, esta es tu computadora; en Colab es la VM temporal de Google. Edge TTS, gTTS, Google Translate, DeepL y Gemini son servicios en línea.

¿Necesito una tarjeta gráfica potente?+

Los números Whisper, NLLB y Piper funcionan en el CPU. Chatterbox también se ejecuta, pero es significativamente más lento. Un NVIDIA-GPU es útil para proyectos más largos.

¿Qué obtengo al final?+

Un vídeo recién doblado y dos archivos SRT: uno con el texto original reconocido y otro con la traducción. El vídeo fuente en sí permanece sin cambios.

¿Puedo cargar archivos directamente desde Google Drive?+

Sí, en la interfaz Colab. Puede especificar una ruta relativa segura dentro de MyDrive y escribir los resultados en una carpeta de Drive.

¿Qué idiomas admite su propia voz de referencia?+

Chatterbox Multilingual V2 admite 23 idiomas básicos, incluidos alemán, inglés, francés, español, italiano, portugués, polaco, turco, japonés, coreano y chino. Piper depende del idioma del modelo seleccionado. gTTS admite muchos códigos de idioma de Google Translate, pero no voces de referencia.

¿Listo para el primer borrador?

Un breve vídeo de prueba es el mejor lugar para empezar.

Comience con Edge TTS o gTTS y los valores predeterminados. Si el proceso te conviene, puedes cambiar tranquilamente a un local o a tu propia voz.
