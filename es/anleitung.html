Preparar una sola vez

Instalar en tu PC con Windows

Necesitas un PC con Windows, conexión a Internet y varios gigabytes de espacio libre. Aún no hay un instalador listo para usar. Los pasos siguientes preparan el programa. No necesitas saber programar.

  1. 01

    Instalar dos programas auxiliares

    Abre el menú Inicio de Windows y escribe PowerShell y abre el programa. Copia las siguientes líneas por separado y pulsa Intro después de cada una. Espera a que termine la instalación antes de pasar a la siguiente.

    PowerShell
    winget install --id Python.Python.3.11 --exact --source winget
    winget install --id Gyan.FFmpeg --exact --source winget

    Python ejecuta LinguoAI. FFmpeg lee y crea vídeos. Si Windows pide confirmación, comprueba que corresponde a esta instalación.

    ¿Listo? Las dos instalaciones indican que han terminado correctamente o que el programa ya está instalado. Ahora cierra PowerShell.

  2. 02

    Descargar y descomprimir LinguoAI

    Descarga el archivo ZIP. En la carpeta de descargas, haz clic sobre él con el botón derecho y elige «Extraer todo». Después abre la carpeta descomprimida.

    Descargar LinguoAI 2.2.1 ↓

    Estás en el lugar correcto si ves el archivo pyproject.toml y la carpeta linguoai en esa carpeta.

  3. 03

    Empezar en la carpeta correcta

    En la carpeta abierta, haz clic arriba en la barra de direcciones. Escribe powershell y pulsa Intro. Se abrirá una ventana nueva. Copia estas tres líneas de comprobación una por una:

    PowerShell
    py -3.11 --version
    ffmpeg -version
    ffprobe -version

    Verás Python 3.11 y otros dos números de versión. Si aparece «no se encuentra», consulta la ayuda de abajo antes de continuar.

  4. 04

    Preparar LinguoAI

    Sigue en esta ventana. Copia cada línea por separado y pulsa Intro. Espera cada vez hasta que puedas volver a escribir. La primera vez se descargarán archivos grandes.

    PowerShell
    py -3.11 -m venv .venv
    .\.venv\Scripts\python.exe -m pip install --upgrade pip
    .\.venv\Scripts\python.exe -m pip install torch --index-url https://download.pytorch.org/whl/cpu
    .\.venv\Scripts\python.exe -m pip install -e ".[desktop]"

    ¿Ha terminado sin errores? La preparación está lista. Solo tienes que hacerla una vez.

  5. 05

    Abrir el programa

    Copia esta línea en la misma ventana:

    PowerShell
    .\.venv\Scripts\python.exe -m linguoai

    Se abre la ventana de LinguoAI. Deja PowerShell abierto mientras uses LinguoAI.

Probar ahora

Tu primer vídeo traducido

Empieza con un vídeo corto en el que se hable con claridad, por ejemplo de 30 segundos.

  1. En „Start“ haz clic en „Datei …“ y selecciona tu vídeo.
  2. Elige el idioma que quieras en „Zielsprache“ . El idioma original se puede detectar automáticamente.
  3. Para esta primera prueba, elige «Google Translate · online» y «Edge TTS · online».
  4. Abre «Erweitert» → «Leistung». En «Hardware für Spracherkennung», elige «Nur CPU». Después vuelve a «Start». Puedes dejar los demás ajustes como están.
  5. Haz clic en „Verarbeitung starten“ . La primera vez, LinguoAI también descarga el modelo de reconocimiento de voz. Puede tardar un poco.
  6. Cuando veas „FERTIG“ haz clic en „Video öffnen“ . Desde „Ordner öffnen“ encontrarás el vídeo y los dos archivos de subtítulos.
Conviene saberlo

En esta prueba sencilla, Google y Microsoft reciben texto para traducirlo y generar la voz. La voz nueva sustituye todo el sonido anterior, incluida la música. Tu archivo original se conserva.

Si no puedes continuar

¿Cómo abro LinguoAI la próxima vez?

Vuelve a abrir la carpeta descomprimida de LinguoAI. Escribe en la barra de direcciones de arriba powershell. Ejecuta solo el comando del paso 5. No tienes que repetir la instalación.

No se encuentra «winget»

Instala o actualiza «Instalador de aplicación» de Microsoft desde Microsoft Store. Después, vuelve a abrir PowerShell y repite el paso 1.

Abrir la guía de Microsoft ↗
No se encuentra Python o FFmpeg

Cierra PowerShell y vuelve a abrirlo como en el paso 3. Si no basta, reinicia el PC y vuelve a comprobar las tres líneas. Para seguir esta guía debes tener Python 3.11 instalado.

Un comando muestra un error

No ejecutes todavía la siguiente línea. Comprueba primero que estás en la carpeta descomprimida que contiene pyproject.toml y de que has copiado la línea completa. Guarda el texto exacto del error por si necesitas ayuda.

Tarda mucho o el vídeo no termina

La primera vez se descargan los modelos. Deja la ventana abierta y comprueba si el proceso avanza. Si LinguoAI muestra un error, lee el mensaje en el registro. Después, prueba con un vídeo más corto.

Cuatro formas de obtener una pista de voz

Comparar voces

“Voz propia” puede significar cosas diferentes. Esta comparación le ayudará a tomar la decisión correcta.

Edge TTS

La manera fácil de comenzar con voces listas para usar del catálogo de Microsoft.

En línea · No, voz de catálogo

gTTS

Rápido Google Voice a través de Google Translate Text-to-Speech con código de voz.

En línea · No, código de idioma

Piper

Salida local rápida con un modelo ONNX existente o autodidacta.

locales · CPU, opcional CUDA

Chatterbox V2

Adopta carácter vocal y forma de hablar a partir de una grabación breve y limpia.

Voz de referencia · GPU recomendado

Agregue Piper localmente

Instale en el mismo entorno virtual y luego cargue una voz adecuada:

.\.venv\Scripts\python.exe -m pip install -e ".[desktop,piper]"
New-Item -ItemType Directory -Force ".\Stimmen"
.\.venv\Scripts\python.exe -m piper.download_voices --download-dir ".\Stimmen" de_DE-thorsten-medium

Piper: ONNX más JSON coincidente, ID de altavoz opcional y velocidad de conversación ajustable.

Voz propia de referencia con Chatterbox

Debido a las dependencias de audio/antorcha, se recomienda un entorno Python-3.11 dedicado:

py -3.11 -m venv .venv-chatterbox
.\.venv-chatterbox\Scripts\python.exe -m pip install --upgrade pip
.\.venv-chatterbox\Scripts\python.exe -m pip install -e ".[desktop,voice-clone]"
.\.venv-chatterbox\Scripts\python.exe -m linguoai
  • 6-10 segundos, una persona, poca reverberación, sin música ni ruido de fondo.
  • Descarga del modelo de aproximadamente 3,7 GB; CPU es posible, pero muy lento para vídeos más largos.
  • La instalación nativa es experimental; Colab o Linux son más confiables para problemas de paquetes de audio.
Usa tu voz responsablemente

Para Chatterbox, es obligatoria la confirmación de que puede utilizar la voz. Utilice su propia grabación u obtenga un permiso explícito. El resultado también contiene una marca de agua PerTh incrustada.

Las voces de referencia contienen características biométricamente sensibles. La confirmación en LinguoAI no reemplaza el consentimiento; El motor Piper y el modelo de voz también pueden tener licencias independientes.

Para procesos repetibles

línea de comando

Este ejemplo se traduce localmente a NLLB y utiliza un modelo Piper. Las mismas configuraciones que en el GUI están disponibles para la automatización.

Salida propia y rutas de modelo.

PowerShell · Piper localmente 
.\.venv\Scripts\python.exe -m linguoai `
  --input "C:\Videos\quelle.mp4" `
  --output "C:\Videos\quelle.de.mp4" `
  --language de `
  --service nllb `
  --device cpu `
  --nllb-device cpu `
  --tts-engine piper `
  --tts-device cpu `
  --piper-model "C:\Stimmen\de_DE-thorsten-medium.onnx" `
  --piper-config "C:\Stimmen\de_DE-thorsten-medium.onnx.json"

Ver todas las opciones: .\.venv\Scripts\python.exe -m linguoai --help

Distribuya la potencia informática de forma sensata

CPU y GPU no son una decisión de todo o nada.

Whisper, NLLB y la voz local se pueden colocar por separado. Por lo tanto, puede empezar poco a poco y colocar en el GPU solo la pieza que realmente se beneficia.

“Automático” comprueba CUDA y, en caso contrario, vuelve a CPU.

Importante: Seleccionar “GPU” no instala automáticamente CUDA.
  • NLLB y Chatterbox

    Necesita una edición CUDA correspondiente de PyTorch.

    Selección PyTorch ↗
  • Faster-Whisper

    Además requiere CUDA-12-cuBLAS y cuDNN 9 en la ruta del sistema.

  • Piper

    Utiliza el tiempo de ejecución ONNX: onnxruntime-gpu instalar en lugar de la edición CPU.

Reconocimiento más rápido opcional con la CPU

¿Parakeet o Whisper?

Parakeet · 25 idiomas

NVIDIA Parakeet v3 reconoce 25 idiomas europeos. El adaptador opcional sherpa-onnx trabaja localmente con la CPU y usa cuatro hilos de forma predeterminada.

Ficha del modelo NVIDIA ↗

Whisper · versátil

Faster-Whisper sigue siendo la opción predeterminada, con detección automática del idioma, una selección más amplia de idiomas y procesamiento con CPU o GPU.

Faster-Whisper ↗

El modelo ajustado de primeline está especializado en alemán. Para él, elige el perfil alemán con una exportación ONNX compatible; para varios idiomas europeos, el perfil NVIDIA. No se garantiza una ventaja de velocidad o calidad sin comparar con tus propios archivos.

Configurar Parakeet

Instala el paquete opcional y prepara una carpeta con un modelo compatible. Los modelos no se descargan automáticamente.

.\.venv\Scripts\python.exe -m pip install -e ".[parakeet]"
.\.venv\Scripts\python.exe -m linguoai --help

Usa la carpeta completa del modelo sherpa-onnx con encoder, decoder, joiner y archivo de tokens. Para la exportación alemana, conserva también el archivo externo del encoder si forma parte del modelo.

En la aplicación de escritorio y en Colab, elige el motor de reconocimiento de voz, el perfil y la carpeta del modelo. Indica explícitamente el idioma de origen para que la traducción reciba el código de idioma correcto. Parakeet transcribe; después se aplican la traducción y la voz elegidas.

La caja de herramientas completa

Todas las funciones en detalle.

Archivos y pedidos
  • Procese un solo video o todos los videos contenidos directamente en una carpeta.
  • Entradas: MP4, MKV, MOV, AVI, WEBM y M4V; Ediciones: MP4, MKV o MOV.
  • Sugerencia de salida automática, nombres sin colisiones y sobrescritura controlada.
  • Avance por expediente, paso de trabajo actual, cancelación y registro técnico.
  • Procesamiento individual y por lotes: sube varios vídeos o introduce rutas de archivos de MyDrive, una por línea. Sube los archivos de Piper y la grabación de referencia o indica sus rutas en MyDrive.
Transcripción con Faster-Whisper
  • Modelos de tiny hasta large-v3, además valores propios del modelo.
  • Detecta automáticamente el idioma de origen o lo establece como código de idioma.
  • CPU, NVIDIA-CUDA o selección automática; int8, float16 y float32 configurables.
  • Secciones de audio superpuestas, compensaciones en tiempo real y limpieza de segmentos duplicados.
  • Longitudes de fragmentos, superposición y número de trabajadores a través de opciones avanzadas o CLI.
Traducción y protección de textos
  • NLLB-200 local, Google Translate sin llave, DeepL-SDK o Gemini.
  • Reserva opcional solo después de una selección explícita; de lo contrario, solo se contactará a un proveedor.
  • URL, direcciones de correo electrónico, monedas, unidades y porcentajes están protegidos durante la traducción.
  • Tiempos de espera, repeticiones limitadas y caché para secciones de texto idénticas.
  • Opcionalmente, Gemini corrige la transcripción Whisper sin cambiar los ID de segmento ni los tiempos.
  • Modelos propios compatibles con NLLB, revisiones fijas, códigos FLORES, límites de lotes y tokens.

El modelo predeterminado NLLB-600M está bajo CC-BY-NC-4.0, es un modelo de investigación y no una traducción de producción certificada. Comprueba siempre los resultados.

Sincronización, tono y exportación.
  • Normalice cada clip a PCM mono de 48 kHz y colóquelo con precisión de muestra.
  • Acelere el habla demasiado larga dentro de un límite configurable.
  • Advertencia al acelerar rápidamente; error controlado en lugar de resultados incomprensibles.
  • Duración exacta del final, metadatos/capítulos adoptados y, si es posible, transmisión de video sin cambios.
  • Grupo de resultados atómicos del nuevo vídeo, SRT original y traducción SRT.
Dónde se procesan tus datos
  • NLLB · Piper · Chatterbox

    Después de descargar en el término elegido. En Colab eso significa dentro de la máquina virtual temporal de Google.

  • Google · DeepL · Gemini

    Reciba solo secciones de texto cuando estén seleccionadas o como un respaldo activado explícitamente.

  • Edge TTS · gTTS

    Envíe cada pista traducida para doblarla al servicio de idioma en línea respectivo.

  • Interfaz web Gradio protegida con contraseña aleatoria por sesión.
  • Caché de modelo opcional y copia de resultados atómicos en Google Drive.
  • Los caminos de acceso permanecen dentro de MyDrive; Drive no se comparte como una carpeta de descarga pública.

Los resultados temporales no se publicarán hasta que el vídeo y ambos subtítulos estén completos. La cancelación, los reintentos limitados, las rutas de destino protegidas y las claves API redactadas evitan sorpresas desagradables.

Lo que el LinguoAI no promete deliberadamente

  • La sincronización sincrónica no es sincronización del movimiento de los labios; la imagen no se cambia.
  • La nueva pista de voz reemplaza completamente el sonido original. Actualmente no se adoptan música, atmósfera ni sonidos.
  • Sin reconocimiento de locutor ni asignación automática de múltiples locutores.
  • Siempre verifique la transcripción, la traducción, la pronunciación y la similitud de voz antes de publicar.
  • Colab-GPU, la duración de la sesión y la finalización de trabajos grandes no están garantizados.

OPCIONAL

Tu propia dirección con Cloudflare Tunnel.

Con SHARE_PROVIDER = "gradio" obtienes automáticamente un enlace dinámico. Google Drive es opcional.

Cloudflare opcional

Solo para una dirección fija propia: configura un Cloudflare Tunnel con nombre, tu dominio y el servicio http://127.0.0.1:7860. No se trata de un servidor público de LinguoAI.

En el Notebook, establece SHARE_PROVIDER en "cloudflare", introduce tu nombre de host en CLOUDFLARE_TUNNEL_HOSTNAME y guarda CLOUDFLARE_TUNNEL_TOKEN como Colab Secret. Nunca publiques el token.

Cloudflare: 95 MB por carga de forma predeterminada. Gradio: hasta 5 GB por archivo. Usa Google Drive para vídeos grandes. No se usan enlaces temporales de trycloudflare.com porque no admiten SSE.
